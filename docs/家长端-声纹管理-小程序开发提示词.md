# 家长端声纹管理 - 小程序 Cursor 开发提示词

将下列内容复制给小程序项目的 Cursor，作为开发声纹管理功能的指令。

---

## 提示词（可直接复制）

```
请按照以下需求实现家长端「声纹管理」功能，接口文档在 docs/家长端-声纹管理页面设计与接口.md，请先阅读该文档。

【一、需要实现的页面】

1. **一级入口卡片**（在设备详情/设置页）
   - 图标：麦克风
   - 标题：声纹管理
   - 副标题：已录入 N 人（N 从接口获取，见下方）
   - 点击：跳转声纹管理详情页，路由携带 deviceId（从设备列表或当前设备传入）

2. **声纹管理详情页**（二级页）
   - 顶部导航：返回 + 标题「声纹管理」
   - 列表：调用 GET /parent-api/device/child/voiceprint?deviceId=xxx 获取数据，每条展示：
     - sourceName（主标题）
     - introduce（副标题，有则展示）
     - createDate（格式化为 YYYY-MM-DD HH:mm 或「X天前」）
     - canManage 为 true 时：显示「播放」「重新录入」「删除」按钮
     - canManage 为 false 时：显示「播放」按钮 +「后台录入」标签，无编辑/删除
   - 底部/悬浮：「添加孩子声纹」按钮

3. **添加/重新录入页**（可选单独页或弹窗）
   - 需先有设备主孩子：点击「添加」时先调 GET /parent-api/device/child?deviceId=xxx，若 data 为 null 则提示「请先添加设备主孩子」并返回
   - 流程：录音或选择 WAV → 上传（POST /parent-api/device/child/voiceprint/upload，multipart/form-data，deviceId+file）→ 保存（POST /parent-api/device/child/voiceprint，JSON body 含 deviceId、childId、audioId、sourceName、introduce）
   - 保存成功后返回详情页并刷新列表

【二、接口与交互】

- 基础地址：{baseUrl}，如 https://xxx.com/xiaozhi
- 所有需鉴权接口：Header 带上 Authorization: Bearer {token}
- deviceId：使用设备列表/设备详情返回的原始 deviceId，**不要对 deviceId 做二次 encodeURIComponent**，否则会报「设备未绑定」

| 场景           | 接口                                                         |
|----------------|--------------------------------------------------------------|
| 进入详情页     | GET {baseUrl}/parent-api/device/child/voiceprint?deviceId=xxx |
| 删除           | DELETE {baseUrl}/parent-api/device/child/voiceprint?voicePrintId=xxx |
| 添加前校验     | GET {baseUrl}/parent-api/device/child?deviceId=xxx           |
| 上传音频       | POST {baseUrl}/parent-api/device/child/voiceprint/upload，form-data：deviceId、file |
| 保存声纹       | POST {baseUrl}/parent-api/device/child/voiceprint，JSON：deviceId、childId、audioId、sourceName、introduce |
| 播放           | 先 POST {baseUrl}/parent-api/device/child/voiceprint/play-token?audioId=xxx 拿 token，再 GET {baseUrl}/parent-api/device/child/voiceprint/play/{token}，将此 URL 设为 wx.createInnerAudioContext().src 后 play() |

【三、播放实现要点】

- 播放接口 GET play/{token} 无需鉴权，可直接作为 InnerAudioContext 的 src
- token 一次性使用，每次点击播放前需重新调用 play-token
- 播放示例：
  wx.request({
    url: baseUrl + '/parent-api/device/child/voiceprint/play-token?audioId=' + encodeURIComponent(item.audioId),
    method: 'POST',
    header: { Authorization: 'Bearer ' + token }
  })
  成功后用 res.data.data 拼成：baseUrl + '/parent-api/device/child/voiceprint/play/' + res.data.data
  赋给 InnerAudioContext.src 并 play()

【四、必须注意】

1. deviceId 不要二次 URL 编码
2. 删除前弹窗二次确认
3. 无主孩子时点「添加」要引导用户先去添加设备主孩子
4. 一级卡片「已录入 N 人」= 声纹列表接口返回的 data.length，可在详情页 onShow 时调接口刷新
```

---

## 使用方式

1. 将 `docs/家长端-声纹管理页面设计与接口.md` 放入可被 Cursor 访问的路径（或粘贴进对话）
2. 复制上方「提示词」中的整段内容，粘贴给 Cursor
3. 根据项目实际情况修改 `{baseUrl}`、路由路径、页面结构等说明
