# 小程序微信审核合规 — 服务端对接说明

> **背景：** 小程序提审因「未体验功能即要求登录 / 无拒绝登录选项 / 内测人群未说明与鉴权」被驳回。  
> **目标：** 支持 **游客浏览 Tab + 按需登录 + 可取消登录**；内测账号 **登录后鉴权**（非一打开就拦死）。  
> **协作：** 本文约定 HTTP 协议、错误码与门禁白名单；**小程序与 xiaozhi-web 可并行开发**，以本文为准联调。  
> **协作状态：** 部分能力服务端尚未上线，见 [§六、协作状态与 Mock](#六协作状态与-mock)；接口字段以本文为准，上线前小程序可本地 mock `public-config`。

**关联文档：**

- [家长端-儿童隐私协议-产品与接口方案.md](./家长端-儿童隐私协议-产品与接口方案.md)
- [家长端-内测保密协议-小程序对接说明.md](./家长端-内测保密协议-小程序对接说明.md)

## 一、产品行为约定（前后端一致）

### 1.1 用户路径

| 阶段 | 行为 | 服务端 |
|------|------|--------|
| 冷启动 | 进入 **Tab 游客态**（默认陪伴页），**不**强制登录 | 允许无 token 访问「公开接口」 |
| 浏览 | 看功能介绍、只读协议正文、帮助等 | 见 §五 白名单 |
| 敏感操作 | 绑定设备、对话、设备列表、孩子档案等 | 无 token → **401** 或业务码 **20001**（见 §3.2） |
| 主动登录 | 用户点「微信登录」→ `POST /auth/wechat` | 正常发 token；内测未开放 → **20031**（见 §3.1） |
| 登录后 | 儿童隐私 → 内测保密（若开关开）→ 业务 | 现有 **20027 / 20029** 不变 |
| 拒绝登录 | 用户点「暂不登录」回 Tab | 无请求 |

### 1.2 明确不做

- **不在**登录页、首页使用 `getPhoneNumber` 强制授权（手机号仍为可选能力，见 §3.4）。
- **不在**未登录时调用 `/consent/status`、`/beta-confidentiality/status` 做全屏拦截（小程序侧保证；服务端 status 仍要求 token 即可）。

### 1.3 内测 vs 对外审核

| 模式 `accessMode` | 说明 |
|-------------------|------|
| `open` | 登录即可用（审核期可临时切此模式 + 提供测试账号） |
| `internal_beta` | 登录后须命中 **内测白名单**（openid），否则 **20031** |

智控台可配置当前模式；小程序从 `GET /app/public-config` 读展示文案，**鉴权以登录接口与业务 token 为准**。

## 二、HTTP 约定

**Base URL：** `https://<域名>/xiaozhi/parent-api`（与现网一致）

**统一响应：**

```json
{
  "code": 0,
  "msg": "string",
  "data": {} 
}
```

`data` 可为 `null`（如业务失败或无载荷时）。

**成功：** 仅 **`code === 0`**。不要用 `20000` 表示成功（现网 parent-api **没有**统一 `20000` 成功码）。

**失败：** `code !== 0`，前端以 `msg` 展示；HTTP 状态码通常为 200（与现网 parent-api 一致），未登录等场景可同时返回 HTTP **401**。

## 三、新增接口

以下路径均相对于 Base URL（例：`GET /app/public-config` → `https://<域名>/xiaozhi/parent-api/app/public-config`）。

---

### 3.1 GET `/app/public-config`（无需登录）

供游客态首页 Banner、登录页说明、Tab 占位文案使用。**不得**返回任何用户/设备/孩子 PII。

**请求：** 无 Body；**不要**求 `Authorization`（有 token 也可访问，响应相同）。

**响应 `data`：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| `accessMode` | string | 是 | `open` \| `internal_beta` |
| `appName` | string | 否 | 展示用，默认「智伴家语」 |
| `homeBanner` | object | 是 | 游客态顶栏 |
| `homeBanner.title` | string | 是 | 如「智伴家语 · 家长端（内测）」 |
| `homeBanner.subtitle` | string | 是 | 如「面向受邀内测家庭…可先浏览功能介绍」 |
| `homeBanner.tags` | string[] | 否 | 如 `["内测", "陪伴机器人"]` |
| `loginHint` | string | 否 | 登录页补充说明 |
| `guestTabHints` | object | 否 | 各 Tab 游客态一句说明，key 建议：`companion` / `agents` / `robot` / `learning` / `mine` |
| `reviewMode` | boolean | 否 | `true` 时建议内测白名单对「审核测试 openid」永远放行（见 §7.3） |
| `updatedAt` | string | 否 | ISO8601 |

**示例：**

```json
{
  "code": 0,
  "data": {
    "accessMode": "internal_beta",
    "appName": "智伴家语",
    "homeBanner": {
      "title": "智伴家语 · 家长端（内测）",
      "subtitle": "当前面向智伴内测家庭开放。您可先浏览功能介绍；使用设备绑定、与孩子对话等服务需登录并完成账号验证。",
      "tags": ["内测", "家长端"]
    },
    "loginHint": "登录使用微信身份，不强制授权手机号。非内测账号可能无法使用完整功能。",
    "guestTabHints": {
      "companion": "登录并绑定设备后，可在此与机器人沟通、查看简报",
      "agents": "登录后可管理并下发对话技能",
      "robot": "登录后可绑定设备、管理孩子档案",
      "learning": "登录后查看学习进展",
      "mine": "登录后管理账号与家庭共享"
    },
    "reviewMode": false,
    "updatedAt": "2026-09-29T12:00:00+08:00"
  }
}
```

**实现建议：**

- 配置存参数字典或独立表，智控台「小程序 → 审核/公开配置」编辑。
- CDN/应用缓存 60s 即可；小程序启动与进 Tab 各拉一次。

---

### 3.2 GET `/app/guest-preview`（无需登录，可选 P1）

若希望游客态「技能 Tab」有真实脱敏数据，可提供；**不做则小程序用静态占位**，不影响 P0 过审。

**响应 `data` 示例：**

```json
{
  "recommendedSkills": [
    {
      "id": "preview_1",
      "name": "睡前故事",
      "description": "示例技能，登录并绑定设备后可下发至机器人",
      "isPreview": true
    }
  ],
  "disclaimer": "以下为示例内容，非您家庭真实数据"
}
```

**约束：** 不得返回设备 ID、孩子姓名、对话记录、真实 userCount 等。

## 四、登录与内测鉴权

### 4.1 POST `/auth/wechat`（现有，行为扩展）

**请求 Body（不变）：**

```json
{
  "code": "<wx.login code>",
  "channel": "mini_program"
}
```

**成功（与现网一致）：** `code=0`，`data.token`、`data.expireAt`、`data.user`（或嵌套 user 字段）。

**新增失败场景 — 内测未开放：**

| code | HTTP | 含义 |
|------|------|------|
| **20031** | 200 | 微信登录成功，但 **未在内测白名单**，**不发放 token**（或发放 `guest` 受限 token，见下） |

**推荐（简单）：** 20031 时 **`data` 为 null**，不写入 parent 会话。

**响应示例：**

```json
{
  "code": 20031,
  "msg": "当前小程序处于内测阶段，您的微信暂未开通使用权限。您可先浏览功能介绍；如有疑问请联系内测客服。",
  "data": {
    "accessMode": "internal_beta",
    "supportHint": "请确认使用购买/受邀时登记的微信，或联系客服 400-xxx"
  }
}
```

**白名单判定顺序建议：**

1. 若 `accessMode=open` → 直接发 token。  
2. 若 `reviewMode=true` 且 openid 在 **审核账号表** → 发 token。  
3. 若 openid 在 **内测白名单**（或已绑定过设备的家长）→ 发 token。  
4. 否则 → **20031**。

**「已绑定过设备的家长」：** 可选策略 — 曾成功 `device/bind` 的 openid 视为自动入白名单，避免老用户被误拦。

---

### 4.2 业务接口 — 未登录访问

**现状：** 多数 parent-api 需 Bearer token。

**约定：**

| 场景 | 建议 |
|------|------|
| 无 token 访问需登录接口 | HTTP **401** 或 body `code=401`，`msg` 含「请先登录」 |
| 小程序游客态 | 不自动跳登录页；仅用户点击敏感功能时再引导登录 |

**可选统一业务码（与 401 二选一，小程序都能识别）：**

| code | 含义 |
|------|------|
| **20001** | 未登录 / token 无效 |

---

### 4.3 已登录但非内测（若采用「受限 token」方案，不推荐 P0）

若未来发 `scope=guest` 的 token：

- 所有写操作与设备/孩子/聊天接口 → **20032**「账号未开通内测完整权限」。  
- **P0 请采用 20031 不发 token**，避免过滤器复杂化。

---

### 4.4 POST `/auth/phone`（可选，P2）

**仅**用户在「我的 → 绑定手机号」主动触发；**不要**作为登录前置。

**请求：**

```json
{
  "code": "<getPhoneNumber 返回的 code>"
}
```

**响应：** 更新 `parent_user.phone`；失败码沿用现网规范。

## 五、网关 / 过滤器白名单（无需 token）

在现有「儿童隐私 / 内测保密 document 可匿名」基础上 **追加**：

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/parent-api/app/public-config` | 游客配置 |
| GET | `/parent-api/app/guest-preview` | 可选预览 |
| GET | `/parent-api/consent/document` | 已有 |
| GET | `/parent-api/beta-confidentiality/document` | 已有 |
| POST | `/parent-api/auth/wechat` | 登录 |
| POST | `/parent-api/auth/**` | 登录相关（按现网） |
| GET | `/parent-api/auth/avatar/file/**` | 若游客页不涉及可仍要求 token |

**仍要求 token + 协议门禁的：**

- `GET /consent/status`、`POST /consent/agree`  
- `GET /beta-confidentiality/status`、`POST /beta-confidentiality/agree`  
- 其余业务 API  

**过滤器顺序（建议不变）：** token 解析 → 401 → 儿童隐私 **20027** → 内测保密 **20029** → 业务。

## 八、错误码汇总（新增部分）

| code | 含义 | 小程序处理 |
|------|------|------------|
| **20001** | 未登录（可选，与 401 等价） | 弹窗引导登录，可取消 |
| **20031** | 内测未开放，未发 token | 登录页展示 `msg` + `supportHint`，按钮「返回浏览」 |
| **20032** | 已登录但无完整权限（若做受限 token） | 专用提示页 |
| 20027 | 须签儿童隐私 | 不变 |
| 20029 | 须签内测保密 | 不变 |
