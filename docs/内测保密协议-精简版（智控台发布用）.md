# 内测保密协议 · 极简醒目版（智控台发布用）

> **参数字典 → 内测保密协议** → 粘贴下列三项 → **发布新版本**。  
> 设计目标：用户 **10 秒内扫完**，只记住 **「三不要 + 反馈可以」**。

---

## 直接复制（推荐上线）

### 标题 `title`

```text
内测须知 · 三不要
```

### 勾选旁摘要 `summary`（勾选框旁，越短越好）

```text
内测未公开：不晒、不传、不转借。提问题请用「内测反馈」。
```

### 正文 `content`（Markdown，一屏内）

```markdown
**您在使用内测样机与内测功能，尚未公开发布。**

---

### 三不要

| | |
|---|---|
| **不要晒** | 朋友圈、小红书、抖音等**公开平台**发样机、截图、视频、未上线功能 |
| **不要传** | 把内测界面、对话、功能细节发给群外或未授权的人 |
| **不要借** | 样机、内测账号**仅限本家庭**使用，勿转借、转售 |

---

### 可以做什么

**小程序「内测反馈」** 随时提问题 — 这是官方渠道，**不算泄密**。

---

勾选 = 我已知悉并同意。协议更新后会再请您确认一次。
```

---

## 小程序展示建议（更醒目）

| 区域 | 放什么 |
|------|--------|
| 页顶大标题 | 用 `title`：**内测须知 · 三不要** |
| 勾选框旁 | 只用 `summary` 一行，**不要**再堆长段 |
| 正文区 | 用 `content` 渲染；表格三行即主视觉，其余弱化字号 |
| 按钮 | 「同意并继续」；不同意仅退出/停留本页 |

若表格在 rich-text 里样式弱，可改成三条加粗小标题（内容不变）：

```markdown
**不要晒** — 公开平台不发样机、截图、视频、未上线功能

**不要传** — 不把内测内容发给未授权的人

**不要借** — 样机与账号仅限本家庭，勿转借转售

**可以** — 「内测反馈」提问题 ✓
```

## 法务可选一行（默认不加，保持短）

若必须写保密期限，**只加一行**在文末：

```markdown
内测期间及结束后 12 个月内，上述要求仍然有效。
```

## 发布步骤

1. 智控台粘贴 **标题 / 摘要 / 正文** → **发布新版本**。  
2. 需要拦截时再开 `parent.beta_conf.enabled`。  
3. 通知用户重新打开小程序签署。
