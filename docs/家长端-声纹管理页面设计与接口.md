# 家长端 - 声纹管理页面设计与接口（小程序实现参考）

后端接口已实现，本文档供小程序端实现「声纹管理」二级页面时使用。

---

## 一、基础信息

| 项目 | 说明 |
|------|------|
| 基础地址 | `{baseUrl}`，如 `http://your-api-host:8002/xiaozhi`（manager-api 的 context-path 为 `/xiaozhi`） |
| 鉴权 | 所有接口需 Header：`Authorization: Bearer {token}` |
| 设备 ID | 从上一级页面（设备详情/设置）传入的 `deviceId` |
| deviceId 格式 | MAC 地址如 `B6:C8:35:D6:10:4`，**切勿对 deviceId 做二次 encodeURIComponent**，否则后端会返回「设备未绑定」；若已编码一次可接受 |

---

## 二、二级页面：声纹管理详情页

### 2.1 页面结构

```
┌─────────────────────────────────────┐
│  < 返回    声纹管理                  │
├─────────────────────────────────────┤
│                                     │
│  [主孩子声纹卡片]                    │
│  ┌─────────────────────────────┐   │
│  │ 小明                         │   │
│  │ 家里孩子，5岁，喜欢恐龙       │   │
│  │ 2026-02-14 10:00             │   │
│  │          [重新录入] [删除]    │   │
│  └─────────────────────────────┘   │
│                                     │
│  [后台声纹卡片]                     │
│  ┌─────────────────────────────┐   │
│  │ 爸爸          [后台录入]     │   │
│  │ 后台录入                     │   │
│  │ 2026-02-13 08:00             │   │
│  │ （无操作按钮）               │   │
│  └─────────────────────────────┘   │
│                                     │
│  [添加孩子声纹] 按钮（底部/悬浮）    │
│                                     │
└─────────────────────────────────────┘
```

### 2.2 列表项设计

| 字段 | 展示位置 | 说明 |
|------|----------|------|
| sourceName | 主标题/姓名 | 声纹来源姓名 |
| introduce | 副标题/描述 | 可为空，有则展示 |
| createDate | 时间 | 格式化为「YYYY-MM-DD HH:mm」或「X天前」 |
| canManage | 控制按钮显隐 | true：显示「重新录入」「删除」；false：仅展示，可加「后台录入」标签 |

### 2.3 交互逻辑

1. **进入页面**：调用「查询声纹列表」接口，渲染列表
2. **重新录入**（`canManage === true`）：跳转录入页（录音/上传 WAV → 调用上传+保存接口）
3. **删除**（`canManage === true`）：弹窗确认 → 调用删除接口 → 刷新列表
4. **添加孩子声纹**：需先有设备主孩子；无则引导先添加主孩子；有则进入录入流程

## 三、接口清单

### 3.1 查询声纹列表（主接口，详情页必调）

**用途**：获取该设备下全部声纹，用于列表渲染和「已录入 N 人」计数。

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `{baseUrl}/parent-api/device/child/voiceprint` |
| Query | `deviceId`（必填） |
| Header | `Authorization: Bearer {token}` |

**响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": [
    {
      "id": "vp-uuid-1",
      "audioId": "a1b2c3d4",
      "sourceName": "小明",
      "introduce": "家里孩子，5岁，喜欢恐龙",
      "createDate": "2026-02-14T10:00:00",
      "canManage": true
    },
    {
      "id": "vp-uuid-2",
      "audioId": "b2c3d4e5",
      "sourceName": "爸爸",
      "introduce": "后台录入",
      "createDate": "2026-02-13T08:00:00",
      "canManage": false
    }
  ]
}
```

**字段说明**：

| 字段 | 类型 | 说明 |
|------|------|------|
| id | string | 声纹 ID，删除时必传 |
| sourceName | string | 姓名 |
| introduce | string | 描述，可能为 null |
| createDate | string | ISO 时间 |
| canManage | boolean | true=可编辑/删除，false=仅展示 |

---

### 3.2 删除主孩子声纹

**用途**：用户点击「删除」且 `canManage === true` 时调用。

| 项目 | 说明 |
|------|------|
| 方法 | `DELETE` |
| 路径 | `{baseUrl}/parent-api/device/child/voiceprint` |
| Query | `voicePrintId`（必填，来自 3.1 的 `data[].id`） |
| Header | `Authorization: Bearer {token}` |

**响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": null
}
```

**注意**：仅 `canManage === true` 的声纹可删除；传 `canManage === false` 的 id 会返回业务错误。

---

### 3.3 上传声纹音频（录入/重新录入第一步）

**用途**：用户录完音或选择 WAV 后，先上传拿到 `audioId`，再调用 3.4 保存。

| 项目 | 说明 |
|------|------|
| 方法 | `POST` |
| 路径 | `{baseUrl}/parent-api/device/child/voiceprint/upload` |
| Content-Type | `multipart/form-data` |
| 参数 | `deviceId`（string）、`file`（WAV 文件，≤10MB） |
| Header | `Authorization: Bearer {token}` |

**响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": "a1b2c3d4-e5f6-7890-abcd-ef1234567890"
}
```

`data` 为 `audioId`，用于 3.4 保存声纹。

---

### 3.4 保存主孩子声纹（录入/重新录入第二步）

**用途**：上传成功后，用 `audioId` + `childId` 保存声纹。需先有设备主孩子。

| 项目 | 说明 |
|------|------|
| 方法 | `POST` |
| 路径 | `{baseUrl}/parent-api/device/child/voiceprint` |
| Content-Type | `application/json` |
| Header | `Authorization: Bearer {token}` |

**请求体**：

```json
{
  "deviceId": "aa_bb_cc_dd_ee_ff",
  "childId": 1,
  "audioId": "a1b2c3d4-e5f6-7890-abcd-ef1234567890",
  "sourceName": "小明",
  "introduce": "家里孩子，5岁"
}
```

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| deviceId | string | 是 | 设备 ID |
| childId | long | 是 | 主孩子 ID，来自「获取设备主孩子」接口 |
| audioId | string | 是 | 3.3 返回的 data |
| sourceName | string | 是 | 姓名/昵称 |
| introduce | string | 否 | 描述 |

**响应示例**：

```json
{
  "code": 0,
  "msg": "success",
  "data": null
}
```

---

### 3.5 获取设备主孩子（录入前校验）

**用途**：点击「添加孩子声纹」时，先调此接口判断是否有主孩子；无则引导用户先添加主孩子。

| 项目 | 说明 |
|------|------|
| 方法 | `GET` |
| 路径 | `{baseUrl}/parent-api/device/child` |
| Query | `deviceId`（必填） |
| Header | `Authorization: Bearer {token}` |

**响应示例**（有主孩子）：

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1,
    "deviceId": "aa_bb_cc_dd_ee_ff",
    "name": "小明",
    "avatarUrl": null,
    "birthday": "2020-05-01",
    "gender": 1,
    "ageStage": "3-6岁",
    "hobbies": "恐龙,听故事",
    "createTime": "2026-02-14T10:00:00",
    "updateTime": "2026-02-14T10:00:00"
  }
}
```

**响应**（无主孩子）：`data` 为 `null`，需引导用户先添加主孩子。

## 四、页面流程汇总

| 场景 | 调用接口 | 说明 |
|------|----------|------|
| 进入详情页 | GET 3.1 查询声纹列表 | 渲染列表，`data.length` 即「已录入 N 人」 |
| 点击删除 | DELETE 3.2 删除声纹 | 仅 `canManage===true` 可删，成功后刷新列表 |
| 点击添加孩子声纹 | GET 3.5 获取主孩子 | 无主孩子则引导添加；有则进入录入流程 |
| 录入流程 | POST 3.3 上传 → POST 3.4 保存 | 先上传拿到 audioId，再保存 |
| 点击重新录入 | 同录入流程 | 一孩一声纹，保存会覆盖旧的 |

---

## 五、错误与边界

| 情况 | 处理 |
|------|------|
| 401 | token 无效，跳转登录 |
| 设备未绑定 | 提示「设备未绑定或不属于当前家长」 |
| 无主孩子时点「添加」 | 引导「请先添加设备主孩子」 |
| 删除 `canManage=false` 的声纹 | 接口会返回「仅可删除主孩子声纹」 |
| 上传非 WAV | 接口可能返回格式错误，前端可限制选择/录制格式 |

## 六、一级入口卡片（可选补充）

在设备详情/设置页的声纹管理入口卡片建议：

- **标题**：声纹管理
- **副标题**：已录入 N 人（N = 3.1 返回的 `data.length`，可从详情页返回时更新或单独调 3.1 获取）
- **点击**：跳转声纹管理详情页，携带 `deviceId`
