# 家长端「内测体验任务」小程序改造说明（含接口）

> 面向小程序开发：入口、任务首页、跳转与 sync。  
> 后端：`manager-api` `/parent-api/beta-mission/*`  
> 智控台：参数管理 → **更多** → **内测任务**

---

## 一、产品约定

| 项 | 约定 |
|----|------|
| 受众 | **仅内测用户**（`is_beta_tester=1`）且全局开关开启 |
| 任务包 | 固定 `beta_core_v1`，8 步、必做 4 步 |
| 引导 | **弱引导**：不冷启动自动跳功能页 |
| 入口 | `showEntry = enabled && betaTester`，**与包完成无关** |
| 体验孩子 | **仅可设一次**；确认按钮后 `PUT /context`；锁定后 20015 |

**入口展示：**

```
showEntry = (server.beta_mission_enabled == true)
         && (parent_user.is_beta_tester == 1)
```

推荐「我的」页轻量拉 `GET /parent-api/beta-mission/entry-status`。

---

## 二、页面结构

```
pages/beta-mission/index      任务首页（章节 + 进度）
pages/beta-mission/complete   必做全完成庆祝（半屏或全屏）
```

建议新增 `utils/api/betaMission.js` 封装下列接口。

---

## 三、接口一览

**Base：** `{baseUrl}/xiaozhi/parent-api/beta-mission`（与 feedback、risk-watch 共用 baseUrl）

**鉴权：** `Authorization: Bearer {token}`

**响应：** `{ code, msg, data }`；`code !== 0` 展示 `msg`。

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/entry-status` | 我的页入口；非内测也 200，`showEntry=false` |
| GET | `/overview` | 任务首页数据；非内测/关开关 → **20011** |
| POST | `/sync` | 自动校验后返回与 overview 相同 data |
| PUT | `/context` | `{ childId }` 锁定体验对象；成功 data=overview |
| POST | `/steps/{stepKey}/skip` | 仅选做步 |
| POST | `/steps/risk_alert_viewed/visit` | B3 访问标记；非内测 20011 静默忽略 |
| POST | `/dismiss-popup` | 首次弹窗「稍后再说」 |

### 3.1 entry-status data

```json
{
  "betaMissionEnabled": true,
  "betaTester": true,
  "showEntry": true,
  "packCompleted": false,
  "contextLocked": false,
  "popupDismissed": false,
  "requiredTotal": 4,
  "requiredDone": 2
}
```

### 3.2 overview / sync data（结构相同）

根级字段：`campaignCode`、`campaignTitle`、`campaignDescription`、`contextChildId`、`contextChildName`、`contextLocked`、`requiredTotal`、`requiredDone`、`packCompleted`、`popupDismissed`、`sections`。

每步 step：

| 字段 | 说明 |
|------|------|
| stepKey | 步骤标识 |
| title / description | 文案 |
| required | 是否必做 |
| verifyMode | `auto` / `visit` |
| status | `pending` / `completed` / `skipped` |
| actionUrl | 后端拼好的路径+query；缺 context 时为 null |
| needsContextChild | true 时先选孩子并 `PUT /context` |
| navigateType | 一期固定 `navigateTo` |

### 3.3 错误码

| code | 含义 |
|------|------|
| 20011 | 非内测或任务未开启 |
| 20012 | 无效 stepKey |
| 20013 | 必做步不可 skip |
| 20014 | childId 无效或无权 |
| 20015 | 体验孩子已锁定 |

## 四、交互要点

### 4.1 我的 Tab

- `showEntry=true` 时显示「内测任务」
- 未完成：副标题 `必做 {requiredDone}/{requiredTotal}`
- 已完成：副标题「已完成」，入口仍保留

### 4.2 任务首页 `index`

- `onShow`、从业务页返回、下拉刷新：调 `POST /sync`，用返回 data 覆盖 state
- 首次进入可拉 `GET /overview`（或先 sync）
- 必做 4 步全 `completed` → `packCompleted=true`，可跳庆祝页

### 4.3 体验孩子

- 锁定前：可用陪伴页 `currentChild` 作默认候选（**不自动 PUT**）
- 用户点「确认体验对象」→ `PUT /context` → 用返回 overview 刷新
- 选孩子列表：`getDeviceList()` + 每台 `getDeviceMainChild(deviceId)`（与 20014 校验同源）
- 锁定后只读，无「更换」

### 4.4 步骤跳转

`needsContextChild=true` 且 `contextChildId` 为空：先走选孩子 + 确认，再 `navigateTo(actionUrl)`。

`actionUrl` 已含 `from=beta_mission&stepKey=xxx`；需要时含 `deviceId`、`childId`。

| stepKey | 目标页（联调基准） |
|---------|-------------------|
| bind_device | `/pages/add-device/add-device` |
| has_child | `/pages/device-main-child/device-main-child` |
| voiceprint_done | `/pages/voiceprint/voiceprint` |
| skill_created | `/pages/create-skill/create-skill` |
| risk_preference_set | `/pages/risk-watch/index` |
| risk_watch_created | `/pages/risk-watch/create-type` |
| risk_alert_viewed | `/pages/risk-alerts/risk-alerts` |
| feedback_submitted | `/pages/feedback/submit` |

### 4.5 首次弹窗（可选）

- 陪伴 Tab `onShow`：若 `!popupDismissed && !packCompleted` 可弹一次
- 「去看看」→ 任务首页；「稍后再说」→ `POST /dismiss-popup`

### 4.6 visit

`pages/risk-alerts/risk-alerts` 的 `onShow` 调 `POST .../risk_alert_viewed/visit`；`code=20011` 时**静默忽略**。

### 4.7 选做跳过

仅 `required=false` 的步骤显示「跳过」→ `POST .../skip`。
