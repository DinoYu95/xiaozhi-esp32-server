# 声纹播放 - 小程序 Cursor 开发提示词

只做声纹列表中的「播放」功能，复制下面提示词给 Cursor：

---

```
请在声纹管理列表的每条声纹卡片上增加「播放」按钮，点击后能播放该条声纹对应的录音。

【播放流程】

1. 用户点击播放时，先调用接口获取一次性 token：
   - 方法：POST
   - URL：{baseUrl}/parent-api/device/child/voiceprint/play-token?audioId={item.audioId}
   - Header：Authorization: Bearer {token}
   - 成功时 res.data.data 即为 playToken

2. 用 playToken 拼成播放地址：
   playUrl = {baseUrl}/parent-api/device/child/voiceprint/play/{playToken}

3. 使用 wx.createInnerAudioContext() 播放：
   const innerAudio = wx.createInnerAudioContext();
   innerAudio.src = playUrl;
   innerAudio.play();

【注意】

- audioId 来自声纹列表接口返回的每条数据的 audioId 字段
- play-token 每次播放前都要重新调，token 一次性使用
- play 接口无需鉴权，可直接作为 InnerAudioContext 的 src
- baseUrl 需包含 context-path，如 https://xxx.com/xiaozhi
```
