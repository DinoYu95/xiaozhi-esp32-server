# 家长端 · 孩子档案与知识图谱匹配（小程序改造说明）

> 后端已在 **manager-api** 落地；教研后台 **升学日期** 在管理员菜单「升学日期」维护。本文供小程序 UI 与联调使用。

## 1. 孩子档案新增字段

与教研 `province_code` / `textbook_edition` **代码完全一致**（不要用自由文本当匹配键）。

| 字段 | 类型 | 说明 |
|------|------|------|
| `provinceCode` | string | 默认 `CN`；`beijing`、`shanghai`、`jiangsu`… 见下表 |
| `textbookEdition` | string | 默认 `generic`；`pep` 人教版、`bnu` 北师大… |
| `currentGrade` | int | 1–12，家长**不可查看高于此年级**的图谱 |
| `textbookSeries` | string | **兼容旧版**，仍可读；新 UI 请只写 `textbookEdition` |

### 1.1 下拉枚举（勿写死，请拉接口）

**GET** `{manager}/parent-api/learning/meta/profile-options`  
（需家长 token，与现有 parent-api 一致）

响应 `data` 示例：

```json
{
  "provinces": [{ "code": "CN", "label": "全国 / 未指定省" }, { "code": "beijing", "label": "北京" }],
  "textbooks": [{ "code": "generic", "label": "课标通用" }, { "code": "pep", "label": "人教版" }],
  "defaults": { "provinceCode": "CN", "textbookEdition": "generic" }
}
```

### 1.2 保存档案

沿用 **POST/PUT** `/parent-api/device/child`，在 body 中增加：

```json
{
  "provinceCode": "beijing",
  "textbookEdition": "pep",
  "currentGrade": 3
}
```

未传时服务端默认：`CN` + `generic` + 原 `textbookSeries` 启发式映射（含「人教」→ `pep`）。

## 2. 知识图谱如何匹配

运行时按 **学科 + 省 + 教材 + 图谱年级** 选 `kg_graph_release`（教研审核发布时已写入维度）。

**回退顺序**（服务端已实现）：

1. `(province, textbook, grade)` 精确  
2. `(province, generic, grade)`  
3. `(CN, textbook, grade)`  
4. `(CN, generic, grade)`  
5. 旧逻辑：该学科最新一条 `published`（兼容未分维度的历史数据）

**家长端年级规则**：

- 掌握地图等接口请求参数 `grade`：若 `grade > child.currentGrade` → **400**「不可查看高于孩子当前年级…」  
- 未传 `grade`：默认 `currentGrade`  
- **允许**查看 `grade ≤ currentGrade`（低年级复习）

**掌握地图 GET** `/parent-api/learning/mastery/map?childId=&subject=math&grade=`

响应新增：

| 字段 | 说明 |
|------|------|
| `childMaxGrade` | 档案年级上限，UI 年级切换器不要超过此值 |

## 3. 升学提醒（小程序主动拉取）

### 3.1 逻辑说明

- 管理员在 **教研后台 → 升学日期** 配置：省（可空=全局）× 学段（小学/初中/高中）× 月/日  
- manager-api **每天 08:00 上海** 扫描所有主孩子档案：  
  - 按 `provinceCode` + 由 `currentGrade` 推断学段匹配配置，无省配则用全局  
  - 若 **今天 = 升学日 − 1 天**，写入提醒  
- 小程序进入学习 Tab / 首页时 **拉取** 是否展示条/banner

### 3.2 接口

**GET** `/parent-api/profile-reminders?childId={childId}`

```json
{
  "code": 0,
  "data": [
    {
      "id": 1,
      "reminderType": "GRADE_PROMOTION",
      "title": "升学季提醒：请更新孩子年级",
      "body": "明天（2026-09-01）为系统配置的升学日…",
      "action": "OPEN_CHILD_PROFILE",
      "remindDate": "2026-08-31",
      "promotionDate": "2026-09-01"
    }
  ]
}
```

**POST** `/parent-api/profile-reminders/{reminderId}/dismiss`  
关闭后当日不再展示（`dismissed_at` 已写）。

### 3.3 小程序 UI 建议

| action | 行为 |
|--------|------|
| `OPEN_CHILD_PROFILE` | 跳转孩子档案编辑页，聚焦 **年级 / 省 / 教材** |

- 学习 Tab 或设备页 `onShow`：`GET profile-reminders?childId=`  
- 有数据则顶部 Banner +「去更新」  
- 点击 dismiss 或完成更新后调用 dismiss

## 4. 小程序改造清单（UI）

1. **孩子档案页**  
   - 新增「所在省/地区」Picker（数据来自 `profile-options.provinces`）  
   - 「教材版本」Picker（`profile-options.textbooks`），默认选中 defaults  
   - 保存时提交 `provinceCode`、`textbookEdition`（保留 `currentGrade`）

2. **学习 · 掌握地图 / 图谱**  
   - 年级切换：1 … `childMaxGrade`（从 mastery/map 响应读取）  
   - 不要提供 `currentGrade+1` 及以上选项  
   - 切换年级时重新请求 `mastery/map?grade=`

3. **提醒 Banner**  
   - 拉取 `profile-reminders`，展示 `title` / `body`  
   - `action=OPEN_CHILD_PROFILE` → 档案页  
   - 关闭 → `dismiss`

4. **兼容**  
   - 旧客户端只传 `textbookSeries` 仍可工作；新客户端务必传 code 字段以便与教研图谱对齐
