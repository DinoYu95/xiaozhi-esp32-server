# 家长端 - 设备规则 小程序接口文档

家长可为已绑定设备设置规则（如「不要讲鬼故事」「少提零食」），智伴在与孩子对话时会遵守这些规则。规则可通过**显式入口**（本接口）或**隐式入口**（家长与智伴聊天时口头设置）添加。

**基础地址**：`{baseUrl}`，如 `http://192.168.88.16:8002/xiaozhi`  
**通用鉴权**：所有接口需在请求头携带 `Authorization: Bearer {token}`，token 来自微信/手机登录返回。

---

## 一、获取设备的家长规则列表

| 项目 | 说明 |
|------|------|
| **URL** | `GET /parent-api/device/rules` 或 `GET /parent-api/device/{deviceId}/rules` |
| **请求头** | `Authorization: Bearer {token}` |
| **请求参数** | `deviceId`（query 或 path，mac 格式如 `B6:C8:35:D6:10:48`，必填） |

**示例请求：**

```
GET /parent-api/device/rules?deviceId=B6:C8:35:D6:10:48
Authorization: Bearer {token}
```

或：

```
GET /parent-api/device/B6:C8:35:D6:10:48/rules
Authorization: Bearer {token}
```

**响应示例：**

```json
{
  "code": 0,
  "msg": "success",
  "data": [
    {
      "id": 1,
      "ruleText": "不要讲鬼故事",
      "createTime": "2025-02-13T10:30:00"
    },
    {
      "id": 2,
      "ruleText": "少提零食",
      "createTime": "2025-02-13T11:00:00"
    }
  ]
}
```

**响应字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 规则 ID，删除时使用 |
| ruleText | string | 规则内容 |
| createTime | string | 创建时间，格式 `yyyy-MM-dd'T'HH:mm:ss` |

---

## 二、添加家长规则

| 项目 | 说明 |
|------|------|
| **URL** | `POST /parent-api/device/rules` 或 `POST /parent-api/device/{deviceId}/rules` |
| **请求头** | `Authorization: Bearer {token}` |
| **Content-Type** | `application/json` |
| **请求参数** | `deviceId` 可通过 query、path 或 body 传递，至少一处必填 |

**请求体：**

```json
{
  "deviceId": "B6:C8:35:D6:10:48",
  "ruleText": "不要讲鬼故事"
}
```

**说明**：

- `deviceId`：设备 ID（mac 格式），可从 path、query 或 body 传入，优先 path > query > body
- `ruleText`：规则内容，必填，不超过 200 字
- 单设备最多 20 条规则，超出返回错误

**示例请求（deviceId 在 path）：**

```
POST /parent-api/device/B6:C8:35:D6:10:48/rules
Authorization: Bearer {token}
Content-Type: application/json

{"ruleText": "不要讲鬼故事"}
```

**示例请求（deviceId 在 body）：**

```
POST /parent-api/device/rules
Authorization: Bearer {token}
Content-Type: application/json

{"deviceId": "B6:C8:35:D6:10:48", "ruleText": "不要讲鬼故事"}
```

**响应示例：**

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 3,
    "ruleText": "不要讲鬼故事",
    "createTime": "2025-02-13T12:00:00"
  }
}
```

---

## 三、删除家长规则

| 项目 | 说明 |
|------|------|
| **URL** | `DELETE /parent-api/device/rules/{id}` |
| **请求头** | `Authorization: Bearer {token}` |
| **路径参数** | `id`（规则 ID，来自列表或添加接口） |

**示例请求：**

```
DELETE /parent-api/device/rules/3
Authorization: Bearer {token}
```

**响应示例：**

```json
{
  "code": 0,
  "msg": "success",
  "data": null
}
```

---

## 四、错误码

| code | 说明 |
|------|------|
| 401 | token 无效或未传 |
| 400 | 参数错误（如 deviceId 为空、ruleText 为空、超过 200 字、单设备超过 20 条） |
| 404 | 设备未绑定当前家长 |

---

## 五、注意事项

1. **deviceId 格式**：使用设备列表返回的原始 deviceId，如 `B6:C8:35:D6:10:48`，**不要对 deviceId 做二次 URL 编码**。
2. **生效时机**：规则添加后，设备下次拉取配置时会收到 `parent_rules`，智伴对话会遵守这些规则。已连接的设备需重新连接或等待下次配置拉取后生效。
3. **隐式添加**：家长在与智伴聊天时说「以后不要跟孩子讲鬼故事」等，智伴会识别意图并调用内部接口添加规则，无需家长在规则页手动添加。
