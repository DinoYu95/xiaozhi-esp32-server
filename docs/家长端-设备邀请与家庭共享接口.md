# 家长端「设备家庭共享 / 邀请绑定」接口文档

> **小程序**：智伴未来家长端  
> **API 前缀**：`/xiaozhi/parent-api`（下文路径均省略此前缀）  
> **鉴权**：`Authorization: Bearer {家长 token}`  
> **响应格式**：`{ "code": 0, "msg": "success", "data": ... }`（失败时 `code` 为非 0 业务码）

**基础地址示例**：`http://39.97.236.17:8002/xiaozhi/parent-api`

---

## 一、产品约定（已确认）

| 项 | 约定 |
|----|------|
| 首绑链路 | 设备屏扫码 → `POST /device/bind` + 6 位 `code`（分钟级有效） |
| 邀请链路 | Owner 分享 → 被邀请人 `POST /device/invite/accept` + `inviteToken`（**与 code 分离**） |
| Owner 解绑 | **解除该设备与所有家长的绑定**，设备可重新首绑 |
| Member 解绑 | **不可**调用 `/device/unbind`；应调用 `POST /device/members/leave` 仅退出自己 |
| 邀请有效期 | **3 天** |
| 单次邀请可用次数 | **1 次**（接受成功后 invite 失效） |
| Member 改设备名/主孩子 | **不可**（只读）；Owner 可改 |

### 角色

| 角色 | 说明 |
|------|------|
| `owner` | 首绑家长（`isPrimaryOwner=true`），可邀请、解绑全员、改设备名/主孩子 |
| `member` | 邀请加入，可看设备与大部分能力，不可解绑整台设备、不可邀请、不可改设备名/主孩子 |

## 二、一期接口（已实现，可联调）

### 2.1 生成邀请（仅 Owner）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `POST /device/invite` |
| **Body** | `{ "deviceId": "B6:C8:35:D6:10:48" }` |

**成功响应 `data`**：

```json
{
  "inviteToken": "明文 token，仅此次返回",
  "expiresAt": "2026-07-10T15:00:00",
  "shareTitle": "邀请你一起管理「大白」",
  "sharePath": "/pages/device-invite/accept?token=xxx",
  "maxUses": 1
}
```

**小程序分享**：`onShareAppMessage` 使用 `sharePath` 与 `shareTitle`。

**错误码**：

| code | msg（中文） | 场景 |
|------|-------------|------|
| 20018 | 仅设备管理员可执行此操作 | 非 Owner |
| 20004 | 设备未绑定 | 设备不存在或未绑定 |
| 10060 | 邀请过于频繁，请稍后再试 | 同一设备每小时超过 10 次 |

---

### 2.2 预览邀请（接受前，需登录）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `GET /device/invite/preview?token={inviteToken}` |

**成功响应 `data`**：

```json
{
  "valid": true,
  "reason": null,
  "deviceId": "B6:C8:35:D6:10:48",
  "deviceName": "大白的机器人",
  "inviterNickname": "爸爸",
  "expiresAt": "2026-07-10T15:00:00",
  "alreadyMember": false
}
```

`valid=false` 时 `reason`：`expired` | `revoked` | `exhausted` | `not_found`

---

### 2.3 接受邀请

| 项目 | 说明 |
|------|------|
| **Method / Path** | `POST /device/invite/accept` |
| **Body** | `{ "inviteToken": "..." }` |

**成功响应 `data`**：

```json
{
  "deviceId": "B6:C8:35:D6:10:48",
  "deviceName": "大白的机器人",
  "message": "加入成功",
  "role": "member",
  "alreadyMember": false
}
```

已是成员时幂等返回：`alreadyMember=true`，`message="您已在该设备中"`。

**错误码**：

| code | msg | 场景 |
|------|-----|------|
| 20019 | 邀请无效或不存在 | token 无效 |
| 20020 | 邀请已过期，请联系对方重新分享 | 过期 |
| 20022 | 不能接受自己发出的邀请 | 邀请人自己点链接 |
| 20023 | 邀请链接已失效 | 已用完/已撤销 |
| 20004 | 设备不存在或已解绑 | Owner 已解绑设备 |

---

### 2.4 设备列表（扩展字段）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `GET /device/list` |

**每项新增字段**：

| 字段 | 类型 | 说明 |
|------|------|------|
| role | string | `owner` \| `member` |
| isPrimaryOwner | boolean | 是否首绑 Owner |
| canInvite | boolean | 是否可发起邀请（Owner 为 true） |
| memberCount | number | 该设备 active 成员总数 |

**响应示例**：

```json
{
  "code": 0,
  "data": [
    {
      "deviceId": "B6:C8:35:D6:10:48",
      "deviceName": "大白的机器人",
      "ownerChildName": "大白",
      "bindTime": "2026-07-01T10:00:00",
      "lastConnectedAt": "2026-07-07T14:00:00",
      "isOnline": true,
      "batteryLevel": 85,
      "wifiName": "Home-WiFi",
      "role": "owner",
      "isPrimaryOwner": true,
      "canInvite": true,
      "memberCount": 2
    }
  ]
}
```

### 2.5 解绑语义（改造）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `POST /device/unbind` 或 `DELETE /device/unbind?deviceId=` 或 `DELETE /device/{deviceId}` |
| **Body** | `{ "deviceId": "..." }` |

| 调用者 | 行为 |
|--------|------|
| **Owner** | 删除该设备**全部** active 绑定；撤销进行中的邀请；设备可重新首绑 |
| **Member** | 返回 **20018**「仅设备管理员可执行此操作」；请用 `POST /device/members/leave` |

---

### 2.6 主孩子 / 设备名权限（改造）

| 接口 | Owner | Member |
|------|-------|--------|
| `GET /device/child` | ✓ | ✓ 只读 |
| `POST /device/child` | ✓ | ✗ 20024 |
| `PUT /device/child` | ✓ | ✗ 20024 |
| `DELETE /device/child` | ✓ | ✗ 20024 |
| `PUT /device/{deviceId}/name` | ✓ | ✗ 20024 |

## 三、二期接口（已实现，可联调）

### 3.1 成员列表（仅 Owner）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `GET /device/members?deviceId={deviceId}` |

**响应 `data`**：

| 字段 | 说明 |
|------|------|
| `parentId` | 家长账号 ID |
| `nickname` | 来自 `parent_user.nickname`（微信登录/个人资料更新写入）；无则 `null`，小程序展示「微信用户」 |
| `avatarUrl` | 头像可访问 URL；无则 `null` |
| `role` | `owner` / `member` |
| `isPrimary` | 是否首绑 Owner |
| `invitedBy` | 邀请人 `parentId`；Owner 为 `null` |
| `joinedAt` | 加入/绑定时间 |

```json
[
  {
    "parentId": 1,
    "nickname": "爸爸",
    "avatarUrl": "https://oss.example.com/avatar/1.png",
    "role": "owner",
    "isPrimary": true,
    "invitedBy": null,
    "joinedAt": "2026-07-01T10:00:00"
  },
  {
    "parentId": 2,
    "nickname": "小明的妈妈",
    "avatarUrl": null,
    "role": "member",
    "isPrimary": false,
    "invitedBy": 1,
    "joinedAt": "2026-07-05T12:00:00"
  }
]
```

**昵称数据来源**：`GET /device/members` 按 `parentId` JOIN `parent_user` 读取。请确保被邀请人在 `POST /auth/wechat` 登录时传入微信 `nickname`（或之后在 `PUT /auth/profile` 更新），否则 `nickname` 为空。

---

### 3.2 移除成员（仅 Owner）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `DELETE /device/members?deviceId={deviceId}&parentId={parentId}` |

不能移除自己（Owner）；不能移除首绑 Owner。失败 **20025**。

---

### 3.3 Member 主动退出

| 项目 | 说明 |
|------|------|
| **Method / Path** | `POST /device/members/leave` |
| **Body** | `{ "deviceId": "..." }` |

Owner 调用会提示「设备管理员请使用解绑设备」。

---

### 3.4 撤销邀请（仅 Owner）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `POST /device/invite/revoke` |
| **Body** | `{ "inviteToken": "..." }` 或 `{ "inviteId": 123 }` |

---

### 3.5 邀请列表（仅 Owner）

| 项目 | 说明 |
|------|------|
| **Method / Path** | `GET /device/invites?deviceId={deviceId}&status=active` |

`status` 可选：`active` | `expired` | `revoked` | `exhausted`

**响应 `data`**：

```json
[
  {
    "inviteId": 10,
    "deviceId": "B6:C8:35:D6:10:48",
    "expiresAt": "2026-07-10T15:00:00",
    "maxUses": 1,
    "usedCount": 0,
    "status": "active",
    "createdAt": "2026-07-07T15:00:00"
  }
]
```

Liquibase：`202607071500.sql`

- `parent_device_binding` 增加：`role`, `is_primary`, `invited_by`, `status`, `updated_at`
- 新建表：`device_invite`

部署 manager-api 后自动执行迁移；历史绑定数据默认 `role=owner`, `is_primary=1`, `status=active`。

```json

  "role": "member",
```

`deviceName` 与 `GET /device/list` 规则一致（优先 `ai_device.alias`，否则主孩子名+「的机器人」）。Member 与 Owner 看到相同设备名。

## 十、对话能力（Member 与 Owner）

### 10.1 两个列表，用途不同

| 接口 | 含义 | Owner / Member |
|------|------|----------------|
| `GET /parent-api/skill/my-list` | **我创建的**对话能力 | 各看各的，可以不同 |
| `GET /parent-api/device/{deviceId}/skills` | **该设备已绑定**的对话能力 | **应一致**（同一 Agent 映射） |

### 10.2 添加时避免重复

绑定前先拉设备已绑定列表，或搜索时带 `deviceId` 自动排除已绑定项：

```
GET /parent-api/skill/search?keyword=&deviceId={deviceId}
```

返回的 `parentSkills` / `recommendedSkills` **不含**已在该设备上的能力。

### 10.3 小程序页面建议

| 区块 | 数据来源 |
|------|----------|
| 我的对话能力 | `GET /skill/my-list` |
| **本设备已启用** | `GET /device/{deviceId}/skills`（Member 只读展示，用于去重） |
| 添加能力时的可选列表 | `GET /skill/search?deviceId=` |

## 八、小程序联调清单

1. 首绑：仍只用 `POST /device/bind` + `code`
2. Owner 设备详情 →「邀请家人」→ `POST /device/invite` → 微信分享 `sharePath`
3. 被邀请人打开 `/pages/device-invite/accept?token=xxx` → 登录 → `GET /device/invite/preview` → `POST /device/invite/accept`
4. 列表页展示 `role` / `canInvite` / `memberCount`
5. Member 不展示「解绑设备」「邀请家人」；可展示「退出共享」→ `POST /device/members/leave`
6. Owner 解绑前二次确认：「将解除所有家人的绑定」

---

## 九、安全说明

- `inviteToken`：≥32 字节随机 + Base64 URL，库内仅存 SHA-256 hash
- 预览/接受必须登录
- 邀请链接不以明文 `deviceId` 为唯一凭证
- 同一 device 生成邀请限流：10 次/小时
- 审计：服务端日志记录 invite 创建、accept、revoke、remove member
