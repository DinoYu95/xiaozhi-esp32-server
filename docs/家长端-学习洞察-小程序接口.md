# 家长端 · 学习洞察（小程序）接口说明

本文档供 **微信小程序 / Cursor** 对接：展示孩子「作业辅导模式」下的 **学习周报**（P1：仅小学数学 G1～G3 精准学情有数据，其余为说明文案）。

**「学习」Tab 全页与掌握地图**：见 [`家长端-学习Tab-小程序开发说明.md`](./家长端-学习Tab-小程序开发说明.md)。

- **服务**：`manager-api`
- **全局前缀**：`server.servlet.context-path`，默认 **`/xiaozhi`**
- **业务前缀**：`/parent-api/learning`
- **鉴权**：与其它家长端一致，请求头 **`Authorization: Bearer {token}`**

**完整 URL 示例**

```
GET https://{你的域名}/xiaozhi/parent-api/learning/weekly-digest?childId=2
```

小程序 `baseUrl` 若已配置为 `{host}/xiaozhi/parent-api`，则相对路径为：

```
GET /learning/weekly-digest?childId=2
```

---

## 一、统一响应格式

```json
{
  "code": 0,
  "msg": "success",
  "data": { }
}
```

| 字段 | 说明 |
|------|------|
| code | `0` 成功；非 0 错误 |
| msg | 提示信息 |
| data | 业务数据 |

**权限**：`childId` 须为当前家长有权访问的 `device_child.id`（与 risk-alerts、shadow-mission 相同）；否则 `code !== 0`。

## 二、学习周报

### 2.1 GET weekly-digest

**请求**

```
GET /xiaozhi/parent-api/learning/weekly-digest?childId={device_child.id}&weekStart={yyyy-MM-dd}
```

| Query | 必填 | 说明 |
|-------|------|------|
| childId | **是** | `device_child.id` |
| weekStart | 否 | 该周 **周一** 日期 `yyyy-MM-dd`；不传则 **本周一**（Asia/Shanghai） |

**响应 `data`：`LearningWeeklyDigestVO`**

```json
{
  "weekStart": "2026-07-28",
  "weekEnd": "2026-08-03",
  "sessionCount": 4,
  "strongSessionCount": 1,
  "mediumSessionCount": 2,
  "weakSessionCount": 1,
  "topWeakSkills": [
    {
      "code": "MATH.G1.SUB.TAKE_AWAY_MEANING",
      "name": "减法的去掉意义",
      "pMastery": 0.42,
      "evidenceCount": 3
    }
  ],
  "errorClassDistribution": {},
  "coverageNote": "当前精准学情支持小学1-3年级数学；语/英作业可陪伴，知识点报告陆续开放。",
  "parentHeadline": "本周作业辅导 4 次，其中拍题/问答有效 3 次。",
  "parentSuggestion": "优先巩固掌握度较低的知识点，可按智伴回炉任务陪孩子练一练。"
}
```

| 字段 | 说明 |
|------|------|
| weekStart / weekEnd | 统计区间（含首尾日） |
| sessionCount | 本周 **作业辅导 session** 次数（孩子说「进入作业辅导」到退出/超时） |
| strongSessionCount | 观测强度 **strong**：本周至少 **1 次拍照** 的 session |
| mediumSessionCount | **medium**：有口头提问、无拍照 |
| weakSessionCount | **weak**：几乎无问答（仅陪伴/超时等） |
| topWeakSkills | 掌握度 **最低** 的最多 5 个知识点（有学情记录才非空） |
| topWeakSkills[].pMastery | 0～1，越小越弱 |
| topWeakSkills[].evidenceCount | 累计证据条数 |
| errorClassDistribution | **P1 常为空对象** `{}`，预留错因分布 |
| coverageNote | 产品能力说明，建议页面底部小字展示 |
| parentHeadline | **主标题**，可直接用大号文案 |
| parentSuggestion | **一条可执行建议** |

**无数据时**：`sessionCount === 0` 时 headline/suggestion 仍为后端生成的引导文案，不是 error。

**观测强度含义（给 UI 注释/tooltip，不必原样给用户看）**

| 级别 | 含义 |
|------|------|
| strong | 有拍题，学情相对可靠 |
| medium | 仅口头问，不代表整本作业对错 |
| weak | 缺少问答，**不能**解读为「学得差/偷懒」 |

## 三、关联能力（已有接口，可选 UI 联动）

### 3.1 孩子年级（影响学情准确度）

保存/更新主孩子时增加字段（与现有 `DeviceChildVO` 一致）：

**PUT** `/xiaozhi/parent-api/device/child`

```json
{
  "childId": 2,
  "currentGrade": 1,
  "textbookSeries": "人教版",
  "subjectsEnabled": "[\"math\"]"
}
```

| 字段 | 说明 |
|------|------|
| currentGrade | 1～6，**建议必填**；未填时设备端学情打标弱 |
| textbookSeries | 可选 |
| subjectsEnabled | 可选，JSON 字符串，如 `["math"]` |

**GET** `/xiaozhi/parent-api/device/child?deviceId=` 返回体含同上字段。

### 3.2 回炉影子任务（可选）

学习系统判错后可能自动下发 **`source=learning`** 的影子任务，列表仍用现有接口：

```
GET /xiaozhi/parent-api/shadow-mission/list?childId=&status=active
```

周报页可增加入口：「查看进行中的回炉练习」→ 跳转现有影子任务页。

## 七、接口列表（小程序对接全集）

| 方法 | 路径 | 说明 |
|------|------|------|
| GET | `/learning/overview` | **推荐首页**：gradeConfigured、graphReady + 嵌套 weeklyDigest |
| GET | `/learning/mastery-map` | **掌握地图**（年级 × 模块 × SKILL；可选 `weekStart`，含 `observedThisWeek` / `consolidateThisPeriod`） |
| GET | `/learning/mastery-map/module-path` | 模块内学习顺序 |
| GET | `/learning/skills/{code}` | 知识点详情（code 需 URL 编码） |
| GET | `/learning/weekly-digest` | 仅周报（与 overview 内 digest 一致） |
| GET | `/learning/sessions` | 本周 session 分页，点进详情 |
| GET | `/learning/sessions/{sessionId}` | 单次辅导 headline、suggestion、skillCodes |
| PUT | `/device/child` | 设置 currentGrade 等（见第三节） |
| GET | `/shadow-mission/active` | 进行中影子任务（含 source=learning） |

### 7.1 GET overview

```
GET /xiaozhi/parent-api/learning/overview?childId=2&weekStart=2026-07-28
```

**data 示例**

```json
{
  "gradeConfigured": true,
  "graphReady": true,
  "currentGrade": 1,
  "textbookSeries": "人教版",
  "subjectsEnabled": "[\"math\"]",
  "weeklyDigest": { }
}
```

`weeklyDigest` 结构同 [2.1 weekly-digest](#21-get-weekly-digest)，且包含：

- `remedialShadowMissions[]`：本周创建的学习回炉任务 `{ id, title, status, skillCode, endsAt, createTime }`
- `errorClassDistribution`：本周诊断中的 `error_class` 计数（如 `concept`）

### 7.2 GET sessions

```
GET /xiaozhi/parent-api/learning/sessions?childId=2&weekStart=&page=1&pageSize=20
```

**data**

```json
{
  "list": [
    {
      "id": 501,
      "startedAt": "2026-07-31T10:00:00.000+00:00",
      "endedAt": "2026-07-31T10:30:00.000+00:00",
      "observationLevel": "strong",
      "userTurnCount": 5,
      "photoCount": 1,
      "durationSec": 1800,
      "endReason": "manual",
      "parentHeadline": "本次有拍题记录，已写入学情。"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20,
  "hasMore": false
}
```

### 7.3 GET sessions/{sessionId}

**data**：含 `parentHeadline`、`parentSuggestion`、`summary`（对象）、`skillCodes[]`。
