## 需求

实现家长端微信小程序的登录与用户信息（昵称、头像）展示与更新功能。

---

## 审核 / 真机登录失败排查（WeChat code invalid → 20002 等）

| 现象 | 后端 code | 常见原因 |
|------|-----------|----------|
| 未配置密钥 | **20038** | 智控台 **参数字典** 缺少 `parent.wechat.app_id`、`parent.wechat.secret`（以前也会统一报 20002） |
| AppID/Secret 错 | **20039** | 提审小程序 AppID ≠ 参数字典；Secret 轮换未更新 |
| code 用过/过期 | **20037** | 连点登录、同一 code 重复 POST、拿到 code 过久才请求（微信 40029/40163） |
| 网络/微信繁忙 | **20040** | 服务器出网、DNS、微信 `-1` |

**必做：**

1. 微信公众平台 → 开发设置：复制 **AppID、AppSecret** → 写入参数字典（与小程序 `project.config.json` 的 appid 一致）。
2. 智控台 → **小程序审核配置**：看顶部 AppID 脱敏提示；未配置会红条告警。
3. 真机：`wx.login` 成功后 **立即** `POST /auth/wechat`，**每次登录重新 wx.login**，不要缓存 code。
4. 看 **manager-api 日志**：`parent wechat jscode2session rejected ... errcode=40029`（不会打 secret/full code）。
5. 审核期：`accessMode=open` + 审核 openid 白名单，避免 20031 与 code 问题叠在一起难查。

## 一、后端接口

### 1. 微信登录

- **URL**：`POST /parent-api/auth/wechat`（实际地址如 `{baseUrl}/parent-api/auth/wechat`）
- **请求体**：`{ "code": "wx.login 返回的 code", "channel": "mini_program", "nickname": "可选", "avatarUrl": "可选" }`
- **响应**：`{ "code": 0, "data": { "token": "xxx", "expireAt": 1234567890, "user": { "id": 1, "nickname": "", "avatarUrl": "", "phone": "" } } }`

### 2. 获取当前用户信息

- **URL**：`GET /parent-api/auth/info`
- **请求头**：`Authorization: Bearer {token}`
- **响应**：`{ "code": 0, "data": { "id": 1, "nickname": "", "avatarUrl": "", "phone": "" } }`

### 3. 更新个人信息（昵称、头像、手机）

- **URL**：`PUT /parent-api/auth/profile`
- **请求头**：`Authorization: Bearer {token}`
- **请求体**：`{ "nickname": "可选", "avatarUrl": "可选", "phone": "可选" }`，只传要更新的字段
- **响应**：`{ "code": 0, "msg": "success" }`

### 4. 头像上传（需新增）

- **URL**：`POST /parent-api/auth/avatar`
- **请求头**：`Authorization: Bearer {token}`
- **请求体**：`multipart/form-data`，字段名 `file`，类型图片
- **响应**：`{ "code": 0, "data": "https://xxx.com/avatars/xxx.png" }`，返回可访问的图片 URL

---

## 二、小程序调用流程

1. **登录**：`wx.login()` 拿到 code → 调用 `POST /parent-api/auth/wechat`，body `{ "code": "xxx", "channel": "mini_program" }` → 存 token 和 user
2. **获取用户信息**：请求头 `Authorization: Bearer {token}` → 调用 `GET /parent-api/auth/info` → 展示 nickname、avatarUrl
3. **更新昵称**：`<input type="nickname">` 获取输入 → 调用 `PUT /parent-api/auth/profile`，body `{ "nickname": "xxx" }`
4. **更新头像**：`<button open-type="chooseAvatar" bind:chooseavatar="onChooseAvatar">` 选头像 → 用 `uni.uploadFile` 或 `wx.uploadFile` 调用 `POST /parent-api/auth/avatar` 上传 → 拿到返回的 URL 后，调用 `PUT /parent-api/auth/profile`，body `{ "avatarUrl": "返回的URL" }`
