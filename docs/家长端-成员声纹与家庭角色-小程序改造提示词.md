# 小程序改造提示词：成员声纹 × 家庭角色锁定

> 可直接复制到小程序仓库给 Cursor / 前端同学。  
> 后端已实现（需部署含 `family_role` + `parent_user_id` 的 manager-api）。

---

## 一、背景与目标

**问题**：`voiceprint-add` 页原先让用户自选「爸爸 / 妈妈 / 其他」，任何人都能代录他人声纹，与家庭共享角色不一致。

**目标**：

1. 家长在**某台设备**上设置了家庭角色（如「爸爸」）后，录声纹时**身份自动锁定**为「爸爸」，**不能再选妈妈/爷爷等**。
2. 未设家庭角色 → 引导先去「家庭共享」设置，**不允许录入**。
3. 与孩子声纹、后台声纹区分清楚，列表可识别类型。

**API 前缀**：`{baseUrl}/parent-api`（`baseUrl` 含 `/xiaozhi`）  
**鉴权**：`Authorization: Bearer {token}`

---

## 二、涉及页面

| 页面 | 改造 |
|------|------|
| `pages/voiceprint/voiceprint-add`（或等价录入页） | **主改**：成员声纹流程，去掉身份 picker，读 context |
| `pages/voiceprint/voiceprint`（声纹管理列表） | 列表项区分 `child/member/admin`；删除/重录看 `canManage` |
| `pages/device-members/` | 已有家庭角色设置（前置依赖） |
| 设备详情/机器人页「录声纹」入口 | 区分跳转：**孩子声纹** vs **我的声纹（成员）** |

---

## 三、两种录入模式（不要混用）

| 模式 | 适用 | 保存接口 | sourceName |
|------|------|----------|------------|
| **孩子声纹** | 录主孩子 | `POST /device/child/voiceprint` | 传孩子昵称 |
| **成员声纹** | 录当前家长本人 | `POST /device/child/voiceprint/member` | **不传**，服务端按家庭角色锁定 |

> 若用户已设家庭角色，后端会拒绝用孩子接口传「爸爸/妈妈」等成人名（code **20034**）。

## 四、成员声纹录入页 UI

### 4.1 进入时必调

```
GET {baseUrl}/parent-api/device/child/voiceprint/member-context?deviceId={deviceId}
```

**响应 `data` 示例（已设角色）**：

```json
{
  "familyRoleSet": true,
  "familyRole": "father",
  "familyRoleLabel": "爸爸",
  "lockedSourceName": "爸爸",
  "requireFamilyRoleFirst": false,
  "hasVoicePrint": false,
  "voicePrintId": null,
  "canManage": true
}
```

**未设角色**：

```json
{
  "familyRoleSet": false,
  "familyRole": null,
  "familyRoleLabel": null,
  "lockedSourceName": null,
  "requireFamilyRoleFirst": true,
  "hasVoicePrint": false,
  "voicePrintId": null,
  "canManage": false
}
```

### 4.2 页面布局示意

**正常可录入（requireFamilyRoleFirst === false）**：

```
┌─────────────────────────────────────┐
│  < 返回    录制我的声纹              │
├─────────────────────────────────────┤
│  ┌─────────────────────────────┐   │
│  │  正在为【爸爸】录制声纹        │   │  ← lockedSourceName，只读，不可点选
│  │  身份来自「家庭共享」设置      │   │
│  └─────────────────────────────┘   │
│                                     │
│  [ 按住说话 / 上传 WAV ]             │
│                                     │
│  hasVoicePrint ? 「将覆盖已有声纹」   │
└─────────────────────────────────────┘
```

**须先设角色（requireFamilyRoleFirst === true）**：

```
┌─────────────────────────────────────┐
│  请先设置家庭角色                    │
│  在「家庭共享」中设置您在家的身份     │

│  [ 去设置 ]  → device-members       │

└─────────────────────────────────────┘
```

### 4.3 必须删除的旧 UI

- ❌ 「爸爸 / 妈妈 / 其他」身份 **picker / ActionSheet / chips**
- ❌ 请求体里自填 `sourceName` 为成人角色
- ❌ 用 `POST /device/child/voiceprint`（孩子接口）录家长声纹

### 4.4 可选保留

- 描述字段 `introduce`（可选，保存时传给 member 接口）
- 录音 / 上传 WAV 交互不变

## 五、成员声纹保存流程

### Step 1 上传音频（与孩子共用）

```
POST {baseUrl}/parent-api/device/child/voiceprint/upload
Content-Type: multipart/form-data

deviceId: MAC
file: WAV（≤10MB）
```

响应：`{ "code": 0, "data": "audioId-uuid" }`

### Step 2 保存成员声纹

```
POST {baseUrl}/parent-api/device/child/voiceprint/member
Content-Type: application/json

{
  "deviceId": "B6:C8:35:D6:10:48",
  "audioId": "上一步返回的 audioId",
  "introduce": "可选描述"
}
```

**不要传 `sourceName`**。服务端读取当前用户在该设备的 `family_role`，写入声纹表。

**成功**：`{ "code": 0, "data": null }` → Toast「声纹已保存」→ 返回声纹列表

**失败**：

| code | 含义 | 前端处理 |
|------|------|----------|
| 20033 | 未设家庭角色 | 弹窗引导去家庭共享 |
| 20034 | 误用孩子接口录成人 | 不应出现；若出现提示换 member 接口 |
| 其他 | 上传/网络等 | 原有错误处理 |

## 六、声纹列表页改造

### 6.1 列表接口（字段扩展）

```
GET {baseUrl}/parent-api/device/child/voiceprint?deviceId={deviceId}
```

**每项新增字段**：

| 字段 | 说明 |
|------|------|
| `voicePrintType` | `child` 主孩子 / `member` 家长成员 / `admin` 后台录入 |
| `parentUserId` | 成员声纹归属家长 ID |
| `mine` | 是否当前用户的成员声纹 |
| `canManage` | 是否可重新录入、删除 |

**示例**：

```json
{
  "id": "vp-uuid-member",
  "sourceName": "爸爸",
  "introduce": null,
  "createDate": "2026-09-09T10:00:00",
  "voicePrintType": "member",
  "parentUserId": 2,
  "mine": true,
  "canManage": true
}
```

### 6.2 列表 UI 规则

| voicePrintType | 标签 | 操作按钮 |
|----------------|------|----------|
| `child` | 「主孩子」 | `canManage` → 重新录入 / 删除 |
| `member` | 「家庭成员」；`mine` 可加「我的」 | `canManage` → 重新录入 / 删除 |
| `admin` | 「后台录入」灰色 | **无**操作按钮 |

**重新录入成员声纹**：仍跳转 `voiceprint-add`（成员模式），走 member-context + member 保存。

**删除**：

```
DELETE {baseUrl}/parent-api/device/child/voiceprint?voicePrintId={id}
```

仅 `canManage === true` 时展示删除；`admin` 类型不可删。

### 6.3 入口按钮文案建议

声纹管理页底部：

- **「添加孩子声纹」** → 孩子录入流（需有主孩子，`POST /voiceprint` + childId）
- **「录制我的声纹」** → 成员录入流（`voiceprint-add` 成员模式）

或合并为一个入口，进入前用路由参数区分：`?mode=child` / `?mode=member`。

## 七、前端伪代码

```javascript
// voiceprint-add.js — 成员模式
const MODE_MEMBER = 'member'

async onLoad(options) {
  this.deviceId = options.deviceId
  this.mode = options.mode || MODE_MEMBER
  if (this.mode === MODE_MEMBER) {
    await this.loadMemberContext()
  } else {
    await this.loadChildContext() // 原有主孩子逻辑
  }
}

async loadMemberContext() {
  const res = await request({
    url: '/parent-api/device/child/voiceprint/member-context',
    data: { deviceId: this.deviceId }
  })
  const ctx = res.data
  this.setData({ ctx })
  if (ctx.requireFamilyRoleFirst) {
    this.setData({ blocked: true })
  }
}

goSetFamilyRole() {
  wx.navigateTo({
    url: `/pages/device-members/device-members?deviceId=${encodeURIComponent(this.deviceId)}`
  })
}

async onSaveVoiceprint(audioId) {
  if (this.data.mode === MODE_MEMBER) {
    await request({
      url: '/parent-api/device/child/voiceprint/member',
      method: 'POST',
      data: {
        deviceId: this.deviceId,
        audioId,
        introduce: this.data.introduce || ''
      }
    })
  } else {
    // 原有孩子声纹 POST /voiceprint
  }
  wx.showToast({ title: '已保存', icon: 'success' })
  wx.navigateBack()
}
```

```javascript
// 列表项展示
function rowTitle(item) {
  if (item.voicePrintType === 'member' && item.mine) {
    return `${item.sourceName}（我的声纹）`
  }
  return item.sourceName
}

function typeBadge(item) {
  switch (item.voicePrintType) {
    case 'child': return '主孩子'
    case 'member': return '家庭成员'
    case 'admin': return '后台录入'
    default: return ''
  }
}
```

## 八、与家庭共享的联动

1. 用户在 `device-members` 设置 `familyRole`（如 `father` → 「爸爸」）
2. 同一 `deviceId` 下进入成员声纹录入 → `lockedSourceName === "爸爸"`
3. 若之后在家庭共享**修改角色**（如改成「爷爷」）并**重新录入声纹**，新声纹 `sourceName` 会更新为「爷爷」（覆盖同 parentUserId 的记录）
4. 若**清除**家庭角色 → 不能再录成员声纹，已有声纹仍在列表中（可删不可新增）

---

## 九、兼容与边界

| 场景 | 处理 |
|------|------|
| 旧版后端无 member-context | 404 时隐藏「录制我的声纹」，仅保留孩子流程 |
| Owner 未设角色 | 与 Member 相同，须先设角色 |
| 一台设备多个家长 | 各录各的，互不覆盖（按 parentUserId 区分） |
| 后台已有「爸爸」admin 声纹 | 列表仍展示；成员「爸爸」另有一条 `member` 类型 |
| deviceId | 勿二次 encode；MAC 格式 `B6:C8:35:D6:10:48` |

---

## 十、自测清单

- [ ] 未设家庭角色 → 录入页 blocked，可跳转 device-members
- [ ] 设为「妈妈」→ 录入页显示「正在为【妈妈】录制」，无身份 picker
- [ ] 保存成功 → 列表出现 `voicePrintType: member`, `mine: true`
- [ ] 重新录入 → 覆盖同一条，不新增第二条
- [ ] Member 不能删他人 member 声纹（`canManage: false`）
- [ ] Owner 可删任意 member 声纹（`canManage: true`）
- [ ] admin 类型无删除按钮
- [ ] 孩子声纹流程不受影响
