# 内测保密协议 — 小程序对接说明

> 与 [儿童隐私协议](./家长端-儿童隐私协议-产品与接口方案.md) 平行的一套能力：内测样机用户须承诺不在社交平台公开内测功能、外观与未发布体验。  
> **默认总开关关闭**（`parent.beta_conf.enabled=false`），智控台开启后才会拦截小程序。

---

## 一、与儿童隐私协议的关系

| 项目 | 儿童隐私协议 | 内测保密协议 |
|------|--------------|--------------|
| API 前缀 | `/parent-api/consent` | `/parent-api/beta-confidentiality` |
| 拦截错误码 | `20027` | `20029` |
| 版本无效 | `20028` | `20030` |
| 是否阻断设备对话 | 是（Owner 未签则 TTS 提示） | **否**（仅拦截小程序 `parent-api`） |
| 签署粒度 | 每个家长账号 | 每个家长账号 |
| 智控台入口 | 参数字典 → 儿童隐私协议 | 参数字典 → **内测保密协议** |

**推荐签署顺序（小程序）：**

1. 登录成功  
2. `GET /consent/status` → 若 `blocking` → 全屏儿童隐私页 → `POST /consent/agree`  
3. `GET /beta-confidentiality/status` → 若 `blocking` → 全屏内测保密页 → `POST /beta-confidentiality/agree`  
4. 进入 Tab 业务页  

两步都通过前，除白名单接口外，业务 API 会先被隐私协议（20027）或内测协议（20029）拦截。

## 二、家长端 API

**Base URL：** 与现有家长端一致，例如 `https://<域名>/xiaozhi/parent-api`  
**鉴权：** `Authorization: Bearer <parent_token>`（`/document` 可不登录）

### 2.1 GET `/beta-confidentiality/document`

获取当前 **published** 协议正文（未登录也可调用，便于登录前展示）。

**响应 `data` 示例：**

```json
{
  "version": "20260924_v1",
  "title": "小智内测样机保密与合规使用承诺",
  "summary": "您使用的设备与小程序功能处于内测阶段…",
  "content": "更新日期：2026-09-24\n\n## 一、内测范围\n…",
  "publishedAt": "2026-09-24T10:00:00+08:00"
}
```

无生效版本时 `data` 可能为 `null`。

### 2.2 GET `/beta-confidentiality/status`

当前登录家长的签署状态（**必须带 token**）。

**响应 `data` 字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| `betaConfEnabled` | boolean | 智控台总开关 |
| `betaConfRequired` | boolean | 是否须签署当前版本 |
| `blocking` | boolean | **true = 应全屏拦截**，禁止进业务 Tab |
| `currentVersion` | string | 当前生效版本号 |
| `agreedVersion` | string \| null | 用户已同意的版本 |
| `agreedAt` | string \| null | 同意时间 |
| `title` | string | 协议标题（便于 UI 展示） |
| `summary` | string | 勾选框旁短文案 |

**示例（需要签署）：**

```json
{
  "betaConfEnabled": true,
  "betaConfRequired": true,
  "blocking": true,
  "currentVersion": "20260924_v1",
  "agreedVersion": null,
  "agreedAt": null,
  "title": "小智内测样机保密与合规使用承诺",
  "summary": "您使用的设备与小程序功能处于内测阶段…"
}
```

**示例（开关关闭或已签署）：**

```json
{
  "betaConfEnabled": false,
  "betaConfRequired": false,
  "blocking": false
}
```

### 2.3 POST `/beta-confidentiality/agree`

同意当前 published 版本（**必须带 token**）。

**请求 Body：**

```json
{
  "version": "20260924_v1"
}
```

`version` **必须**与 `GET /status` 或 `/document` 返回的 `currentVersion` 一致，否则 `code=20030`。

**响应：** 与 `GET /status` 相同结构（签署后 `blocking=false`）。

**幂等：** 同一用户同一版本重复提交不报错。

## 三、错误码

| code | 含义 | 小程序建议 |
|------|------|------------|
| `20029` | 须先同意内测保密协议 | 跳转内测保密全屏页（与 20027 隐私页分开） |
| `20030` | 协议版本无效或已过期 | 重新拉 `/document` + `/status` 后再提交 |
| `20027` | 须先同意儿童隐私协议 | 仍走现有隐私页（先于内测页处理） |

统一响应格式（与现网一致）：

```json
{
  "code": 20029,
  "msg": "须先同意内测保密协议",
  "data": null
}
```

## 四、门禁白名单（无需已签署即可访问）

与儿童隐私类似，以下路径**不会**因未签内测协议被 `20029` 拦截：

- `POST /parent-api/auth/**`（登录）
- `GET /parent-api/consent/document|status`、`POST /parent-api/consent/agree`
- `GET /parent-api/beta-confidentiality/document|status`、`POST /parent-api/beta-confidentiality/agree`
- `GET /parent-api/auth/info`（可选）
- `GET /parent-api/auth/avatar/file/**`
- `POST /parent-api/chat/snapshot/device-upload`

**其余所有 `parent-api`：** 若开关开启且未签当前版本 → `20029`。

注意：若儿童隐私也未签，会先返回 **`20027`**（过滤器顺序：token → 隐私 → 内测保密）。

## 五、小程序实现清单

### 5.1 页面建议

| 页面 | 说明 |
|------|------|
| `pages/consent/privacy` | 已有：儿童隐私全屏 |
| `pages/consent/beta-confidentiality` | **新增**：内测保密全屏，UI 可复用隐私页组件 |

内测页要素：

- 展示 `title`、`content`（Markdown 渲染，与隐私页一致）
- 勾选框旁展示 `summary`
- 按钮「同意并继续」→ `POST /agree` 带 `currentVersion`
- 按钮「不同意」→ 仅可退出登录或停留本页（与隐私策略一致）

### 5.2 启动 / Tab `onShow` 流程（伪代码）

```javascript
async function ensureAgreements() {
  const consent = await api.get('/parent-api/consent/status')
  if (consent.data.blocking) {
    wx.redirectTo({ url: '/pages/consent/privacy' })
    return false
  }
  const beta = await api.get('/parent-api/beta-confidentiality/status')
  if (beta.data.blocking) {
    wx.redirectTo({ url: '/pages/consent/beta-confidentiality' })
    return false
  }
  return true
}
```

### 5.3 全局请求拦截

在现有 `20027` 处理旁增加：

```javascript
if (res.data.code === 20029) {
  wx.redirectTo({ url: '/pages/consent/beta-confidentiality' })
  return
}
if (res.data.code === 20030) {
  // toast 提示后刷新 document/status
}
```

### 5.4 协议升级

智控台「发布新版本」后，`agreedVersion !== currentVersion` → `blocking=true`，启动时再次全屏；文案可用：「我们更新了内测保密承诺，请重新阅读并同意。」

## 六、智控台（运营 / 法务）

路径：**参数字典 → 更多 → 内测保密协议**

- **总开关**：对应参数 `parent.beta_conf.enabled`（默认 `false`）
- **编辑标题 / 摘要 / 正文** → **发布新版本**（自动生成版本号 `YYYYMMDD_vN`）
- **历史版本**、**未签署名单** 与儿童隐私页相同逻辑

上线内测前建议：

1. 法务审阅默认正文（库表 `parent_beta_conf_document` 种子 `20260924_v1`）  
2. 打开总开关  
3. 通知内测用户重新打开小程序完成签署

## 七、部署与迁移

- Liquibase：`202609241800.sql`（表 + 默认协议 + 参数）  
- 部署 **xiaozhi-web**（含 manager-api + manager-web）  
- 无需改 xiaozhi-server / 设备固件（本协议不绑设备 TTS）  

**验证 curl（替换 TOKEN）：**

```bash
BASE=https://<host>/xiaozhi

curl -s "$BASE/parent-api/beta-confidentiality/document" | jq .

curl -s -H "Authorization: Bearer $TOKEN" \
  "$BASE/parent-api/beta-confidentiality/status" | jq .

curl -s -X POST -H "Authorization: Bearer $TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"version":"20260924_v1"}' \
  "$BASE/parent-api/beta-confidentiality/agree" | jq .
```
