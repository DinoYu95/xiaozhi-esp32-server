# 家长端技能接口文档（小程序端）

家长在小程序端可创建、查询、更新、删除自己的自定义技能（与管理员在后台添加的 ai_skill 分开存储）。

**基础地址**：`{baseUrl}`，如 `http://192.168.88.16:8002/xiaozhi`  
**通用鉴权**：所有接口需在请求头携带 `Authorization: Bearer {token}`，token 来自微信登录返回。

---

## 一、查询我添加的技能

### 1.1 我添加的技能列表

| 项目 | 说明 |
|------|------|
| **URL** | `GET /parent-api/skill/my-list` |
| **请求头** | `Authorization: Bearer {token}` |
| **请求参数** | 无 |

**响应示例（成功）：**

```json
{
  "code": 0,
  "msg": "success",
  "data": [
    {
      "id": 1,
      "name": "讲故事",
      "description": "给孩子讲故事",
      "instructions": "当用户要求讲故事时...",
      "version": "1.0",
      "tools": null,
      "metadata": null,
      "createTime": "2025-02-13T15:30:00",
      "updateTime": "2025-02-13T15:30:00"
    }
  ]
}
```

**响应字段说明：**

| 字段 | 类型 | 说明 |
|------|------|------|
| id | number | 技能 id，更新/删除时使用 |
| name | string | 技能名称 |
| description | string | 技能描述 |
| instructions | string | 技能指令/系统提示 |
| version | string | 版本 |
| tools | string | 工具列表 JSON，可为 null |
| metadata | string | 元数据 JSON，可为 null |
| createTime | string | 创建时间 |
| updateTime | string | 更新时间 |

## 二、创建技能

### 2.1 创建家长自定义技能

| 项目 | 说明 |
|------|------|
| **URL** | `POST /parent-api/skill` |
| **请求头** | `Authorization: Bearer {token}` |
| **Content-Type** | `application/json` |

**请求体：**

```json
{
  "name": "技能名称",
  "description": "简短用途说明",
  "instructions": "技能说明/系统级提示，发给模型",
  "version": "1.0",
  "tools": "[\"play_music\"]",
  "metadata": "{}"
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| name | string | 是 | 技能名称 |
| instructions | string | 是 | 技能指令/系统提示 |
| description | string | 否 | 简短用途说明 |
| version | string | 否 | 版本号，默认 1.0 |
| tools | string | 否 | 工具 id 列表，JSON 数组字符串，如 `["play_music"]` |
| metadata | string | 否 | 扩展字段，JSON 对象字符串 |

**响应示例（成功）：**

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "id": 1,
    "name": "讲故事",
    "description": "给孩子讲故事",
    "instructions": "当用户要求讲故事时...",
    "version": "1.0",
    "tools": null,
    "metadata": null,
    "createTime": "2025-02-13T15:30:00",
    "updateTime": "2025-02-13T15:30:00"
  }
}
```

## 五、按关键词模糊搜索（家长自定义 + 官方推荐，结构分开）

| 项目 | 说明 |
|------|------|
| **URL** | `GET /parent-api/skill/search?keyword={关键词}&deviceId={设备ID}` |
| **请求头** | `Authorization: Bearer {token}` |
| **请求参数** | `keyword`：可选，不传或传空则返回全部；传值则按 name、description 模糊匹配；`deviceId`：可选，传则从 parentSkills、recommendedSkills 中排除已绑定到该设备的，避免重复展示 |

**响应示例（成功）：**

```json
{
  "code": 0,
  "msg": "success",
  "data": {
    "parentSkills": [
      {
        "id": 1,
        "name": "讲故事",
        "description": "给孩子讲故事",
        "instructions": "...",
        "version": "1.0",
        "tools": null,
        "metadata": null,
        "createTime": "2025-02-13T15:30:00",
        "updateTime": "2025-02-13T15:30:00"
      }
    ],
    "recommendedSkills": [
      {
        "id": "play_music",
        "name": "播音乐",
        "description": "播放音乐",
        "instructions": "...",
        "version": "1.0",
        "tools": "[\"play_music\"]",
        "metadata": null,
        "isOfficialRecommended": 1,
        "createTime": "2025-02-13T10:00:00",
        "updateTime": "2025-02-13T10:00:00"
      }
    ]
  }
}
```

**说明**：

- `parentSkills`：家长自己创建的技能，结构同「我添加的技能」
- `recommendedSkills`：官方推荐技能，id 为 string，多 `isOfficialRecommended` 字段
- 模糊匹配字段：`name`、`description`
- `keyword` 为空或不传时，返回两边的全部数据
- **去重**：传 `deviceId` 时，已在设备上绑定的技能不会出现在 parentSkills 和 recommendedSkills 中；skillId 与已绑定列表的 skillId 格式一致（官方=string，家长=number）

## 六、绑定 / 解绑技能到设备

> **说明**：以下接口需后端实现。家长可将「官方推荐技能」或「自己创建的技能」绑定到已绑定的设备（对应设备的 agent），家长 id 从 token 自动解析。

### 6.1 绑定技能到设备

| 项目 | 说明 |
|------|------|
| **URL** | `POST /parent-api/device/{deviceId}/skill/bind` |
| **path 参数** | `deviceId`：设备 ID（mac） |
| **请求头** | `Authorization: Bearer {token}` |
| **Content-Type** | `application/json` |

**请求体：**

```json
{
  "skillSource": "official",
  "skillId": "play_music",
  "speakerType": "owner_child"
}
```

**字段说明：**

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| skillSource | string | 是 | 技能来源：`official` 官方推荐，`parent` 家长自建 |
| skillId | string | 是 | 官方技能：ai_skill.id（如 `play_music`）；家长技能：parent_user_skill.id（如 `1`） |
| speakerType | string | 是 | 说话人类型：`owner_child` / `parent` / `other_child` / `other_adult` / `unknown` |

**家长 id**：从请求头 token 解析，无需传入。

**响应示例（成功）：**

```json
{
  "code": 0,
  "msg": "success",
  "data": null
}
```

**业务逻辑**：

1. 校验设备已绑定给当前家长
2. 校验技能存在且有权使用（官方：直接可用；家长自建：需归属当前家长）
3. 写入 `ai_agent_skill_mapping`：官方 skillId 直接存；家长 skillId 内部转为 `parent_{id}` 以便与 ai_skill 区分

---

### 6.2 解绑设备技能

| 项目 | 说明 |
|------|------|
| **URL** | `DELETE /parent-api/device/{deviceId}/skill/bind` |
| **path 参数** | `deviceId`：设备 ID（mac） |
| **请求参数（query）** | `skillSource`：`official` \| `parent`；`skillId`：技能 id；`speakerType`：说话人类型 |
| **请求头** | `Authorization: Bearer {token}` |

**请求示例：**

```
DELETE /parent-api/device/aa:bb:cc:dd:ee:ff/skill/bind?skillSource=official&skillId=play_music&speakerType=owner_child
```

**响应示例（成功）：**

```json
{
  "code": 0,
  "msg": "success",
  "data": null
}
```

---

### 6.3 错误码（绑定/解绑）

| code | 说明 |
|------|------|
| 20001 | 家长 token 无效或已过期 |
| 20007 | 设备未绑定给当前家长 |
| 20008 | 技能不存在或无权使用 |
| 20009 | 该技能已绑定到该说话人类型 |

---

### 6.4 已存在设备无技能时的修复

家长扫码绑定**新建**的设备时，后端会自动为 agent 配置官方推荐技能。若设备是之前绑定的（旧逻辑未自动配置），可执行以下 SQL 为**尚无技能映射**的 agent 补全官方推荐技能：

```sql
-- 1. 查哪些 agent 尚无技能映射
SELECT d.id AS device_id, d.agent_id
FROM ai_device d
LEFT JOIN ai_agent_skill_mapping m ON d.agent_id = m.agent_id
WHERE m.id IS NULL AND d.agent_id IS NOT NULL AND d.agent_id != '';

-- 2. 批量为上述 agent 插入官方推荐技能（一行 SQL 补齐所有无技能的 agent）
INSERT INTO ai_agent_skill_mapping (agent_id, speaker_type, skill_id, create_time, update_time)
SELECT d.agent_id, 'owner_child', s.id, NOW(), NOW()
FROM ai_device d
CROSS JOIN ai_skill s
LEFT JOIN ai_agent_skill_mapping m ON d.agent_id = m.agent_id
WHERE m.id IS NULL
  AND d.agent_id IS NOT NULL
  AND d.agent_id != ''
  AND s.is_official_recommended = 1;
```

## 九、小程序调用示例（uni.request）

```javascript
// 查询我添加的技能
uni.request({
  url: baseUrl + '/parent-api/skill/my-list',
  method: 'GET',
  header: {
    'Authorization': 'Bearer ' + token
  },
  success: (res) => {
    if (res.data.code === 0) {
      const list = res.data.data;
      console.log('我的技能', list);
    }
  }
});

// 创建技能
uni.request({
  url: baseUrl + '/parent-api/skill',
  method: 'POST',
  header: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  },
  data: {
    name: '讲故事',
    description: '给孩子讲故事',
    instructions: '当用户要求讲故事时，根据孩子年龄选择合适的故事...'
  },
  success: (res) => {
    if (res.data.code === 0) {
      console.log('创建成功', res.data.data);
    }
  }
});

// 按关键词搜索技能
uni.request({
  url: baseUrl + '/parent-api/skill/search',
  method: 'GET',
  header: {
    'Authorization': 'Bearer ' + token
  },
  data: {
    keyword: '故事'  // 可选，不传则返回全部
  },
  success: (res) => {
    if (res.data.code === 0) {
      const { parentSkills, recommendedSkills } = res.data.data;
      console.log('我的技能', parentSkills);
      console.log('官方推荐', recommendedSkills);
    }
  }
});

// 绑定技能到设备（官方推荐 or 家长自建）
uni.request({
  url: baseUrl + '/parent-api/device/' + deviceId + '/skill/bind',
  method: 'POST',
  header: {
    'Authorization': 'Bearer ' + token,
    'Content-Type': 'application/json'
  },
  data: {
    skillSource: 'official',   // 'official' | 'parent'
    skillId: 'play_music',    // 官方用 ai_skill.id，家长用 parent_user_skill.id
    speakerType: 'owner_child'
  },
  success: (res) => {
    if (res.data.code === 0) {
      console.log('绑定成功');
    }
  }
});
```
