# 家长端 · 风险提示通知订阅（Owner 配置被邀请人）

> **背景**：当前 `parent_risk_notification` 投递逻辑对设备上**全部 active 绑定家长**各写一条（见 `ChildRiskServiceImpl.flushOutboxItem`）。  
> **目标**：仅 **Owner（设备管理员）** 可配置「哪些被邀请 Member 接收风险提示」；Owner 本人始终接收。

**关联文档**：

- 风险提示列表（已有）：`docs/家长端-儿童风险提示-小程序接口.md`
- 家庭共享 / 成员：`docs/家长端-设备邀请与家庭共享接口.md`

---

## 一、产品规则

| 角色 | 接收通知 | 配置权限 |
|------|----------|----------|
| **Owner** | **始终接收**（不可关闭） | 可为每个 Member 开关「接收风险提示」 |
| **Member** | 默认 **不接收**；Owner 开启后才接收 | 不可改他人、不可改 Owner |

**说明**：

- 「接收」= 风险 outbox 投递时为其写入 `parent_risk_notification`，小程序告警列表 / 未读红点可见。
- 未订阅的 Member：**不写入通知**；小程序应隐藏或禁用「风险告警」入口（见前端约定）。
- 新成员接受邀请后：`receiveRiskNotify = false`，Owner 在设置页手动开启。
- Owner 关闭某 Member 后：仅影响**之后**新产生的告警；历史通知不删除。

---

## 二、数据模型（manager-api）

在 `parent_device_binding` 增加字段：

| 字段 | 类型 | 默认 | 说明 |
|------|------|------|------|
| `receive_risk_notify` | TINYINT(1) | Owner=1，Member=0 | 是否接收该设备孩子的风险提示 |

**迁移**：Liquibase 新 changelog；存量数据 `UPDATE ... SET receive_risk_notify=1 WHERE role='owner'`，Member 保持 0 或按产品改为 1（推荐 **Member 默认 0**，避免未经 Owner 同意就推送）。

**投递改造**（`flushOutboxItem`）：

```java
for (ParentDeviceBindingEntity b : binds) {
    if (!shouldReceiveRiskNotify(b)) continue;
    // insert parent_risk_notification ...
}
// shouldReceiveRiskNotify: owner 恒 true；member 看 receive_risk_notify==1
```

## 三、接口设计

**Base**：`{baseUrl}/xiaozhi/parent-api`  
**鉴权**：`Authorization: Bearer {家长 token}`

### 3.1 查询订阅配置（仅 Owner）

| 项目 | 说明 |
|------|------|
| **GET** | `/device/{deviceId}/risk-notify-subscribers` |

**权限**：当前用户须为该设备 **Owner**，否则 `20018`。

**响应 `data`**：

```json
{
  "deviceId": "B6:C8:35:D6:10:48",
  "deviceName": "大白的机器人",
  "ownerAlwaysReceive": true,
  "members": [
    {
      "parentId": 1,
      "nickname": "爸爸",
      "avatarUrl": "https://...",
      "role": "owner",
      "receiveRiskNotify": true,
      "canEdit": false,
      "joinedAt": "2026-07-01T10:00:00"
    },
    {
      "parentId": 2,
      "nickname": "妈妈",
      "avatarUrl": null,
      "role": "member",
      "receiveRiskNotify": false,
      "canEdit": true,
      "invitedBy": 1,
      "joinedAt": "2026-07-05T12:00:00"
    }
  ]
}
```

| 字段 | 说明 |
|------|------|
| `canEdit` | Owner 行 `false`；Member 行 `true`（仅 Owner 可调） |
| `receiveRiskNotify` | 当前是否订阅 |

---

### 3.2 保存订阅配置（仅 Owner）

| 项目 | 说明 |
|------|------|
| **PUT** | `/device/{deviceId}/risk-notify-subscribers` |

**Body**：

```json
{
  "items": [
    { "parentId": 2, "receiveRiskNotify": true },
    { "parentId": 3, "receiveRiskNotify": false }
  ]
}
```

**规则**：

- 仅处理 `role=member` 的 `parentId`；忽略 Owner 自身、非本设备成员。
- 不允许 `items` 里把 Owner 设为 `false`（若传入 Owner id，忽略或 `20025`）。
- 幂等：未出现在 `items` 中的 Member **保持不变**（或产品可选「全量覆盖」— 推荐 **部分更新**）。

**成功**：`{ "code": 0, "msg": "success", "data": null }`

**错误码**：

| code | 场景 |
|------|------|
| 20018 | 非 Owner |
| 20004 | 设备无绑定 |
| 20025 | parentId 不是该设备 Member（可选） |

---

### 3.3 当前用户是否可收告警（Member / Owner 均可）

| 项目 | 说明 |
|------|------|
| **GET** | `/device/risk-notify-access?deviceId={deviceId}` |

**响应 `data`**：

```json
{
  "deviceId": "B6:C8:35:D6:10:48",
  "role": "member",
  "receiveRiskNotify": false,
  "canManageSubscribers": false
}
```

| 字段 | 说明 |
|------|------|
| `receiveRiskNotify` | 当前登录家长在该设备上是否会收到新告警 |
| `canManageSubscribers` | 是否 Owner（用于展示「通知设置」入口） |

**用途**：小程序 Tab /「我的」里决定是否展示风险告警入口与红点（未订阅则不展示或灰显）。

---

### 3.4 扩展已有接口（可选，减少请求）

**`GET /device/list`** 每项增加：

```json
{
  "receiveRiskNotify": true,
  "canManageRiskNotify": false
}
```

- `receiveRiskNotify`：同 3.3  
- `canManageRiskNotify`：即 `role===owner`

**`GET /device/members`** 每项增加 `receiveRiskNotify`、`canEdit`（与 3.1 一致），Owner 管理页可复用 members 接口而不单独 GET 3.1。

> **推荐**：实现 **3.1 + 3.2 + 3.3**；3.4 作为二期优化。

## 四、小程序页面与交互

### 4.1 入口（仅 Owner）

路径建议：`pages/device/risk-notify-settings`  
入口位置（任选）：

- 设备详情 / 家庭共享 → 「风险通知设置」
- 风险告警列表页右上角「管理通知对象」（仅 Owner 可见）

### 4.2 页面结构

1. 顶部说明：「选择哪些家人接收孩子的风险提示。管理员本人始终会收到。」
2. 列表：
   - **管理员（你）**：固定展示，右侧「始终接收」标签，不可点
   - **被邀请成员**：`switch` 绑定 `receiveRiskNotify`
3. 保存：离开页 `onUnload` 批量 PUT，或底部「保存」按钮

### 4.3 Member 侧

- 调用 `GET /device/risk-notify-access` 或读 `device/list.receiveRiskNotify`
- `false`：不展示「风险告警」菜单、不调 `unread-count`、不跳转 `pages/risk-alerts/*`
- `true`：行为与现网一致（见 `docs/家长端-儿童风险提示-小程序接口.md`）

### 4.4 与现网风险接口关系

| 接口 | 变更 |
|------|------|
| `GET /risk-alerts?childId=` | 无变更；未订阅者本无新记录 |
| `GET /risk-alerts/unread-count` | 未订阅者返回 0 |
| 风险观察 `risk-watch/*` | 与通知订阅独立；Member 能否提交观察仍按现网 Member 只读规则 |

## 八、FAQ

**Q：Member 默认要不要收通知？**  
A：推荐默认 **不收**，由 Owner 显式开启，符合「管理员授权」产品表述。

**Q：一个家长绑多台设备，订阅是否独立？**  
A：是，按 `parent_device_binding` 行（deviceId 维度）配置。

**Q：智控台超管要管吗？**  
A：本期仅小程序 Owner；平台侧仍用现有儿童风险配置，不涉及家长订阅。
