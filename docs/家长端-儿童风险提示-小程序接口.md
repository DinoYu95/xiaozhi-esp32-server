# 家长端 · 儿童风险提示（小程序）接口说明

本文档供 **微信小程序 / Cursor** 对接：展示智伴侧上报并经智控台投递的「儿童风险」通知列表、未读数、详情与已读标记。

- **服务**：`manager-api`
- **全局前缀**：`application.yml` 中 `server.servlet.context-path`，默认为 **`/xiaozhi`**
- **业务前缀**：`/parent-api/risk-alerts`
- **鉴权**：与现有家长端一致，请求头携带 **`Authorization: Bearer {token}`**（token 来自 `POST /parent-api/auth/wechat` 或 `POST /parent-api/auth/phone/login` 返回的 `ParentLoginVO.token`）

**完整 URL 示例**

```
https://{你的域名}/xiaozhi/parent-api/risk-alerts?childId=2&page=1&pageSize=20
```

---

## 一、统一响应格式

```json
{
  "code": 0,
  "msg": "success",
  "data": {}
}
```

| 字段 | 说明 |
|------|------|
| code | `0` 成功；非 0 为错误码 |
| msg | 提示信息 |
| data | 业务数据；失败时多为 null |

**未鉴权**：HTTP 200，body 中 `code` 为未授权错误（过滤器写入 JSON），小程序需根据 `code !== 0` 跳转重新登录。

---

## 二、接口列表

### 2.1 分页列表（某孩子的风险提示通知）

**请求**

```
GET /xiaozhi/parent-api/risk-alerts?childId={device_child.id}&page=1&pageSize=20
```

| Query | 必填 | 默认 | 说明 |
|-------|------|------|------|
| childId | **是** | — | 设备主孩子 ID，对应表 `device_child.id` |
| page | 否 | 1 | 页码，从 1 开始 |
| pageSize | 否 | 20 | 每页条数，最大 100 |

**响应 `data`：`ParentRiskNotificationPageVO`**

```json
{
  "list": [
    {
      "id": 100,
      "childId": 2,
      "eventId": 55,
      "title": "【请关注】孩子成长对话提示",
      "summary": "命中规则摘要…",
      "riskLevel": 2,
      "isRead": 0,
      "createTime": "2026-03-31T12:00:00.000+00:00"
    }
  ],
  "total": 1,
  "page": 1,
  "pageSize": 20,
  "hasMore": false
}
```

| 字段 | 说明 |
|------|------|
| riskLevel | `1` 最严重，`3` 最轻 |
| isRead | `0` 未读，`1` 已读 |
| summary | 列表用摘要（服务端可能对原文截断） |

**权限**：若当前家长与该 `childId` 无绑定关系，返回业务错误（非 0 code）。

---

### 2.2 未读条数（红点）

**请求**

```
GET /xiaozhi/parent-api/risk-alerts/unread-count
GET /xiaozhi/parent-api/risk-alerts/unread-count?childId=2
```

| Query | 必填 | 说明 |
|-------|------|------|
| childId | 否 | 不传则统计当前家长 **全部孩子** 的未读；传入则只统计该孩子 |

**响应 `data`**：`number`（Long），未读条数。

---

### 2.3 单条详情（详情页展示完整说明）

**请求**

```
GET /xiaozhi/parent-api/risk-alerts/{notificationId}
```

| Path | 说明 |
|------|------|
| notificationId | `parent_risk_notification.id`，即列表项里的 `id` |

**响应 `data`：`ParentRiskNotificationDetailVO`**

```json
{
  "id": 100,
  "childId": 2,
  "eventId": 55,
  "title": "【请关注】孩子成长对话提示",
  "summary": "命中规则摘要…",
  "riskLevel": 2,
  "isRead": 0,
  "createTime": "2026-03-31T12:00:00.000+00:00",
  "category": "social",
  "reasonPublic": "对外可读的原因或命中片段全文",
  "sessionId": "uuid-session",
  "source": "RULE",
  "eventStatus": "DONE",
  "eventCreateTime": "2026-03-31T11:59:00.000+00:00"
}
```

| 字段 | 说明 |
|------|------|
| category | 智控台规则分类字符串 |
| reasonPublic | **建议在详情页展示**；来自风险事件的对外说明 |
| sessionId | 对话会话 ID（排查 / 联调用） |
| source | 如 `RULE` 等 |
| eventStatus | 如 `WAIT_NOTIFY`、`DONE`、`SUPPRESSED` |
| eventCreateTime | 风险事件创建时间；若关联事件缺失可能为 null |

**权限**：仅能查看归属当前家长的通知；同时会校验家长与孩子绑定。

---

### 2.4 标记已读

**请求**

```
POST /xiaozhi/parent-api/risk-alerts/{notificationId}/read
```

Body：无（可不传 Content-Type）。

**响应 `data`**：`null`

---

## 三、与业务流程的关系（给产品 / 前端理解用）

1. 智伴检测到风险 → `POST` 智控台内部接口写入 `child_risk_event` → outbox 异步投递。
2. 投递成功后写入 **`parent_risk_notification`**，家长在本组接口中读取。
3. **只有进入通知表的记录**才会出现在小程序列表（被全局关闭、冷却、级别过滤等逻辑拦截的事件可能不会给家长发通知，但仍可能在管理端事件表中存在）。

---

## 四、小程序实现要点（给 Cursor）

1. **BASE_URL**：拼接 `https://域名 + context-path(/xiaozhi) + /parent-api/...`。
2. **Header**：每次请求带 `Authorization: Bearer ${token}`。
3. **列表页**：`GET .../risk-alerts?childId=当前孩子 id`；触底加载增大 `page`。
4. **Tab 红点**：轮询或进入首页时调 `GET .../risk-alerts/unread-count?childId=`。
5. **详情页**：点列表项后 `GET .../risk-alerts/{id}`；进入详情后可调 `POST .../risk-alerts/{id}/read` 消除未读。
6. **错误处理**：`code !== 0` 时 toast `msg`；鉴权失败引导重新登录。
